# case=5 — a backup older than 180 days thaws, then restores

alterpath (rare × costly) · sharp · cell r14 · sketch, not proof

## .narrative

in may the commander shelved a spike on `grove-3` and let the grove go. in december he wants it
back. its object sits in `DEEP_ARCHIVE`, where a plain get fails. the restore does not fail with
a raw `InvalidObjectState`; it asks s3 to thaw a copy, says it waits 12–48 hours, prints the
exact command to resume, and exits 0. two days later he runs that same command, the thawed copy
reads, and the tree lands.

## .timeline

```
given an object for `grove-3 / tree=spike` dated 2026-05-02, class DEEP_ARCHIVE
when [t0] `rhx grove.backup.restore --from grove-3 --repo ahbode/spike --tree spike`
  then it requests the thaw (RestoreObject), and exits 0 with
    🌙 grove-3 · tree=spike sits in DEEP_ARCHIVE
       ├─ thaw requested at 2026-12-04T10:00Z
       ├─ eta: 12–48h
       └─ resume with the same command:
          rhx grove.backup.restore --from grove-3 --repo ahbode/spike --tree spike
when [t1] the same command, while the thaw is still in progress
  then it lays no files, requests no second thaw, and prints the elapsed wait
when [t2] the same command, once the thawed copy reads
  then the tree lands as in case=2 [t1]
```
