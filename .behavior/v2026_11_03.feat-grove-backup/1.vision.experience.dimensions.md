# 1.vision.experience.dimensions — grove backup

## .the shape: shared axes, then goal-conditioned axes

the axes are NOT all orthogonal, and the structure says why. **goal** is the latent dimension:
several axes mean naught outside one goal (an object class means naught to an enroll). so the
space is a set of per-goal sub-products. each sub-product's axes are orthogonal within it.

### shared axes — read by more than one goal

| # | axis | values |
|---|------|--------|
| A | actor | `timer` (the agent; no human) · `crew` (a brain on the grove, as camper) · `commander` (the human who owns the fleet) |
| K | grove kind | `ec2` · `hetzner` · `laptop` (`local@unix`) · `cicd` |
| R | reach | `ok` · `no-grove-name` · `no-bucket-name` · `no-credential` (the chain answers naught) · `denied` (the chain answers, and s3 refuses the verb — a grant, not a retry, cures it) |
| C | concurrency | `alone` · `with-same-goal` (two backups, or two restores) · `with-other-goal` (a restore while a backup runs) |

**R's values are checked in that written order, and the first that fails is the cause reported.**
so a box short of two (no credential AND no bucket name) reports `no-grove-name`, then
`no-bucket-name`, then `no-credential`, then `denied` — the local declarations before the network
call, and the credential before the verb it carries. that rule verdicts every multi-failure tuple
at once. `denied` differs from the run-time fault `F=put-error`: a retry never cures a 403, so it
fails the whole run, never one unit.

### goal-conditioned axes

| goal | axis | values |
|------|------|--------|
| back up | U unit | `clone` · `worktree` · `home=.claude` · `home=.rhachet` |
| back up | T content | `never-put` (no prior object) · `unchanged` (equals the unit's latest object, any date) · `changed` · `mid-write` (a file changes while tar reads it) |
| back up | H schedule | `on-time` · `missed` (box asleep or down at the hour) |
| back up | F run-time fault, once reach is ok | `none` · `put-error` (s3 5xx, throttle, a network blip) · `disk-full` (the root-only temp tar cannot be written) |
| observe | O state | `ok` · `failed` · `stale` (last ok > 2h) · `never-ran` · `not-enrolled` |
| restore | U unit | as above |
| restore | S seat, relative to the unit | `same` (the caller's own home) · `other` (another seat's, e.g. camper on `user=ground`). a backup has no S: the root timer has no caller seat and walks every `/home/*` alike |
| restore | Y object class | `readable` (STANDARD, GLACIER_IR) · `deep-archive` |
| restore | G target, for `clone` | `absent` · `present-clean` · `present-dirty` |
| restore | G target, for `worktree` | `absent, clone live` · `absent, clone absent` · `present` |
| restore | G target, for `home` | `absent` · `present` |
| restore | B branch relation, for a clone graft | `new` · `equal` · `ahead` (ff) · `diverged` |
| restore | X branch checked out in the live clone, for a clone graft | `no` · `yes` (git refuses a fetch into it) |
| list | L scope | `every grove` · `one grove` |
| enroll | P seat applied | `ground` (sudo) · `camper` (no sudo) |

## .goal-applicability — the impossible tuples, by nature

| tuple | why impossible |
|---|---|
| `timer × {observe, list, restore, enroll}` | the timer runs one verb: back up |
| `K ∈ {laptop, cicd} × {back up, observe}` | no agent there: the bundle declines on `local@*`, so no run happens and no status is written |
| `crew × enroll × P=ground` | a crew runs as camper; it holds no ground seat |
| any goal-conditioned axis × a goal it does not belong to | e.g. an object class for a backup run; a schedule state for a list |
| `restore × R=no-grove-name` | a restore names its source with `--from`; the box's own name is not read |

## .the walked sub-products

| goal | axes | tuples | how the inventory walks them |
|------|------|--------|------------------------------|
| back up | K{ec2,hetzner} × R × C × U × T × H × F | 2·5·3·4·4·2·3 = 2880 | R≠ok fails the RUN before any unit, uniform over U·T·H·F (rows per R); with R=ok, U × T walked in full (16), H and K uniform but stated; C per value; F≠none uniform over U·T — one rule: retry the unit once, then name it, run ✗ (b20). no A: a hand run and a timer run execute one service; the actor reaches the outcome only through C, which b15 walks |
| observe | A{crew,commander} × K{ec2,hetzner} × O | 2·2·5 = 20 | uniform over A (one line, one file); per O; K splits the remote surface (stats vs probe) |
| list | A × L × R{ok, no-bucket-name, no-credential, denied} | 2·2·4 = 16 | uniform over A; per L × R. no `no-grove-name`: a list reads the bucket's prefixes, never the box's own name. K is not an axis here: a list runs wherever a caller holds reach, a laptop included, and R verdicts it |
| restore | S × R × C × U × Y × G × B × X | per unit's own G | per U × G; Y uniform over U (stated); B × X for clones (8); S, R, C per value; a unit absent under `--from` is r22; K is not an axis, for the list's reason |
| enroll | A{crew,commander} × K × P | 2·4·2 = 16 | per K × P; A uniform except crew × ground (impossible) |

a row that covers several tuples names them, and the one rule that verdicts all of them.

## .the forbidden cells (rejection invariants — nurture: the behavior must refuse)

- a plaintext credential in the bucket (`~/.claude/.credentials.json`, `~/.rhachet/keyrack/vault/os.direct/`), in ANY cell — the bucket is readable by every grove's role, so a plaintext credential there is one every grove holds
- a restore that overwrites a present file — a live clone's uncommitted edits, and a fresh grove's provisioned `~/.claude`, both die under an overwrite, and no version of them exists anywhere else
- a backup run that moves a session file's mtime — the ec2 idle-hibernate clock reads those mtimes, so a moved one holds the box awake
- a bucket name typed into this repo — the repo is public (`rule.forbid.dox-in-public-repo`)
- a ✓ over a gap: a run reports ok while a unit it owed was skipped, failed, or never found (`rule.forbid.failhide`)
