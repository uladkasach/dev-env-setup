# 1.vision.experience.dimensions

## .the primary axes

| axis | values | why no value on it forces a value on another axis |
|---|---|---|
| event | `--mode plan` · `--mode apply` · a tmux server crash · a reaper tick | any event can meet any machine, any installed tmux, any layout, any linger state; the axes that DO depend on the event are nested under it below |
| affected human | crew owner (at the laptop) · diagnoser (after a crash) · none | a crew owner lives an apply (case 3), a crash (case 6), a reaper tick (case 9); a diagnoser can read a core after any crash. no event fixes who is affected |
| machine | cloud grove · laptop (`local@unix`) | either machine can hold any installed tmux, any collector state, any layout, and any linger state |
| installed tmux | none · apt 3.2a · the pinned 3.5a | the binary on PATH is a fact about the file, set by apt, keepalive, or this route — independent of machine role and of the event about to run |
| core collector | absent · present | `systemd-coredump` is a separate package; a box may hold it with any tmux, on any machine |
| server layout | one shared server · one server per crew | chosen by the crew verbs (nheuron), not by the tmux build, the machine, or the event |
| seat linger | every seat lingers · the runner lingers, another seat does not | a logind fact per seat; no tmux, collector, or layout value implies it |

## .conditional sub-axes — each exists only under a parent value, and says so

| sub-axis | exists only when | values |
|---|---|---|
| operator | event ∈ {plan, apply} | `ground` (sudo) · `camper` (no sudo) |
| wire | event = apply | tarball sha matches · sha mismatch · the fetch returns no bytes |
| build | event = apply ∧ wire = match | succeeds · fails |
| build stage | event = apply ∧ wire = match | a temp dir, a log dir, and a placement all succeed · no temp dir · no build-log dir · the built binary cannot be placed |
| live server version | installed tmux = the pinned 3.5a | every live server matches the installed binary · a pre-swap server still alive |
| live server answer | event = plan ∧ a socket is found | the server answers and names its build · the server answers and names no build · the socket answers not (a corpse) · every socket is a corpse, so no server answers |
| live server terminal | event = plan ∧ a live server answers | its `default-terminal` matches the conf · differs from the conf |
| pane TERM | live server terminal = matches | every pane spawned after the conf reached the server · a pane spawned before it, with an older TERM |
| live server plugin hook | event = plan ∧ a live server answers | no server runs a removed plugin's hook · a server still runs one |
| conf parse | event = apply | `~/.tmux.conf` parses · it does not parse, so the isolated server starts with no `@plugin` for tpm |
| collector install | event = apply ∧ core collector = absent | systemd-coredump installs · the install fails |
| core_pattern holder | core collector = present | systemd-coredump holds it · another sysctl.d handler sorted after it holds it · the pattern is unreadable |
| server birth | server layout = one per crew | in a scope of its own · inside another crew's pane (that crew's cgroup) |
| load | event = crash | a lone call · a storm of clients (one every 1–3s) |
| server age | event = reaper tick | under 24h · over 24h |

the nested shape is the honest one: a crash has no operator, a plan has no wire, and a
"pre-swap server" exists only after a swap. each was a correlated axis when crossed flat.
