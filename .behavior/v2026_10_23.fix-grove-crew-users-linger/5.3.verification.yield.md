# 5.3.verification — yield

## .the suites of this repo

`package.json` declares no test command (only `prepare`), so no `npm run test:*` exists. this
repo's test suites are:

| suite | what it is | command |
|---|---|---|
| parse | every tracked shell file parses | `rhx shell.syntax.verify` |
| plays | every tracked `.play/permanent/prove.*` play — fixture arms, each red/green clamped | `rhx play.run --all` |

no 2.1.criteria or 3.2.distill.repros artifact is declared on this route; the journeys come from
the experience catalog (`1.vision.experience.case=_.md`).

`play.run` had no way to run the whole set, so `--all` was added (each play through the same index,
verb and bound gates as `--play`; a decline counts as a fail, never a pass). and `--resnap`, for
the snaps below.
