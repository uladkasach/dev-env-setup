# case=14 — another handler holds core_pattern

## .narrative

the package `systemd-coredump` ships a sysctl.d file that points `core_pattern` at its collector.
sysctl.d applies files in name order, so a file sorted after the package's — another crash
handler, a hand edit — wins, and the kernel pipes each core elsewhere. the package is installed,
and a check that read only the install would say ✔ while the next tmux segfault leaves no core
coredumpctl can show: the wish's own pain, behind a green row. so the apply reads the live
pattern after `sysctl --system`, and ✋s when the package is present yet not the holder.

```

           core_pattern to another handler
```

`prove.coredump-verify-reads-core-pattern` snaps [t2]; U2 of the same play snaps the [t4] row.
