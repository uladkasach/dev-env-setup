# case=7 — ground meets a tarball whose sha does not match

## .narrative

ground runs the apply. the fetch returns bytes whose sha256 differs from the pin — a tampered
mirror, or a re-tagged release. ground sees a ✋ that names both sums before any build starts,
checks `tmux -V`, and finds the prior tmux untouched; the crews never noticed.

## .timeline

```
[t0] given any box, with any prior tmux
[t1] when  ground runs `rhx grove.provision --what 2.8.tmux --mode apply`
           and the tarball sha256 ≠ the pin
[t2] then  ground reads:
           ✋ tmux-3.5a.tar.gz sha256 <got> ≠ the pin <want>
              ⇒ not built; the prior tmux is untouched
[t3] then  ground's `command -v tmux` and `tmux -V` read as before [t1]
```

fail-safe via `web_verify_sha256` (`rule.require.verify-binary-downloads`): fast (before any
build), loud (✋ with both sums), safe (no file changed).
