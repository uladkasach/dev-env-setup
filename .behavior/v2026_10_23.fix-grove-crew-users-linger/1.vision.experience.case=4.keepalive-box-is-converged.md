# case=4 — the keepalive-built box is already converged

## .narrative

the live box already holds the 3.5a keepalive built by hand. ground's first provision apply
reads the binary, finds the pinned version, and builds naught.

## .timeline

```
[t0] given /usr/local/bin/tmux reports tmux 3.5a (keepalive's build)
[t1] when  ground applies 2.8.tmux
[t2] then  • tmux 3.5a at /usr/local/bin/tmux, the pinned version ✔ — no fetch, no build
```

the state is read from the binary (`command -v tmux` + `tmux -V`), so two builds of one
version are one state.
