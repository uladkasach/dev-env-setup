# case=5 — linger reaches every seat, not just the seat that ran provision

## .narrative

ground lingers; camper, who hosts the crews, does not. today keyrackd sees "ground lingers ✔"
and stops, so camper's user manager dies at its last logout. ground applies the linger bundle;
it reads each login seat, grants camper, and from then on the verify names any seat still
without linger with a ✋ and the one command that fixes it.

## .timeline

```
[t0] given ground Linger=yes, camper Linger=no
[t1] when  ground applies the linger bundle
[t2] then  • ground lingers ✔ (read, no write)
[t3] then  • camper did not linger; granted ✔
[t4] when  the verify runs on a box where a grant failed
[t5] then  ✋ camper does not linger
           ⇒ its user manager dies at its last logout
           fix: sudo -v && rhx grove.provision --what <linger bundle> --mode apply
```

fail-safe: a failed grant is ✋, not today's 🌙.
