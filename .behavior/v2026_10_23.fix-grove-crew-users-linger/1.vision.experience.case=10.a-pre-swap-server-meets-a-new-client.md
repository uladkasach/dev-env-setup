# case=10 — a pre-swap 3.2a server meets a 3.5a client

## .narrative

after the swap, the crews still run on their old 3.2a server. the crew owner's verbs now reach it
through the 3.5a client. both speak protocol 8, so attach, send, and read work. a command whose
flags 3.2a lacks is refused by the server with its own error. camper's plan names each server
that still runs the old build. while every crew shares one server, a restart ends every crew on
it, so the plan hands the call to a human and prints no command that ends a server. once each
crew holds its own server (nheuron#44), a crew's revive moves only that crew onto 3.5a.

## .timeline

```
[t0] given the crews on one 3.2a server, /usr/local/bin/tmux at 3.5a
[t1] when  the crew owner runs `duct.read` / `duct.send` on crew A
[t2] then  both answer — protocol 8 on both sides
[t3] when  camper (the seat that owns the crews' socket) runs
           `rhx grove.provision --what 2.8.tmux --mode plan`
[t4] then  🌙 1 live server(s) still run a build older than the pin
              ⇒ no apply restarts them, and no seat inside one should: a restart ends EVERY
                session on that server — while crews share one server, that is every crew on it
              next: a human decides when those sessions may end
              servers: default=3.2a
[t5] when  a human ends the shared server, and the crews revive onto a fresh one
[t6] then  the plan reads `• 1 live server(s) run the pinned build (3.5a) ✔`
```

fail-safe: no crew is killed to converge; the old server is named, not hidden, and the only seat
that sees it is never handed a command that would end its own session. 🌙, not ✋, since the box
is healthy and a ✋ that every post-swap box trips would cry wolf. a ground seat reads only its
own servers, so it does not see this line.
