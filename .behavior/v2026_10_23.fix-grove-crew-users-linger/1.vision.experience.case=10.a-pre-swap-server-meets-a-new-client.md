# case=10 — a pre-swap 3.2a server meets a 3.5a client

## .narrative

after the swap, crew A still runs on its old 3.2a server. the crew owner's verbs now reach it
through the 3.5a client. both speak protocol 8, so attach, send, and read work. a command whose
flags 3.2a lacks is refused by the server with its own error; the verify names which servers
still run the old build, and a revive moves crew A onto 3.5a.

## .timeline

```
[t0] given crew A on a 3.2a server, /usr/local/bin/tmux at 3.5a
[t1] when  the crew owner runs `duct.read` / `duct.send` on crew A
[t2] then  both answer — protocol 8 on both sides
[t3] when  ground runs `rhx grove.provision --what 2.8.tmux --mode plan`
[t4] then  🌙 1 live server runs tmux 3.2a, older than the pinned 3.5a: <socket>
              ⇒ it keeps its crew alive; a revive moves it to 3.5a
[t5] when  the crew owner revives crew A
[t6] then  the plan reads every live server at 3.5a ✔
```

fail-safe: no crew is killed to converge; the old server is named, not hidden, and the fix is a
revive the crew owner already knows. 🌙, not ✋, since the box is healthy and a ✋ that every
post-swap box trips would cry wolf.
