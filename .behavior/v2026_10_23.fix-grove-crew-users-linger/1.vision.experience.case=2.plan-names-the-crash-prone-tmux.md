# case=2 — the plan names the crash-prone tmux; it does not pass it

## .narrative

ground surveys a grove whose PATH tmux is still the jammy 3.2a. today the verify prints
`tmux present (3.2a) ✔`. after, it refuses, says why that build matters on a grove, and hands
the one command that converges it.

## .timeline

```

[t1] when  `rhx grove.provision --what 2.8.tmux --mode plan`

           ⇒ a crash of a tmux server ends every seat on it
           fix: sudo -v && rhx grove.provision --what 2.8.tmux --mode apply

```
