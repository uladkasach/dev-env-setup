# case 4 — plan names the leak

the commander suspects a leak — a hook fired where it should not. plan answers without a write:
which roles, how many hooks each, and whether the file is writable. each line ends in the one
command that fixes it. it names only what is unmet.

```
given [c4.a] home settings writable, zero role hooks, patch current
  when [t0] rhx grove.provision --what 5.3.brains --mode plan
    then verify ✋ names the write bit, and only the write bit
    then it prints: fix: rhx grove.provision --what 5.3.brains --mode apply
    then the file is byte-equal to the before

given [c4.b] home settings locked, one role hook, patch current
  when [t0] rhx grove.provision --what 5.3.brains --mode plan
    then verify ✋ lists the role hook by author, with its count; no write-bit claim
    then it prints: fix: rhx grove.provision --what 5.3.brains --mode apply
    then the file is byte-equal to the before
```
