# case 3 — re-apply converges, still locked

the commander re-runs the whole provision a week later. the bundle sees the file already holds the
patch, no role hooks, and no write bit — so it neither backs up nor builds a tmp nor writes. it prints
`[KEEP]`, the same shape the global config half already uses for a file that holds its value.

this keeps backups from pile-up: one per real change, never one per apply.

```
given [c3] home settings locked + clean + patch already merged
  when [t0] apply
    then it prints [KEEP]; no backup is written; the file is never opened for write
    then file byte-equal to before; mode 0400
  when [t1] apply again
    then same
```
