# wish: the home claude settings hold no role hooks, and only dev-env-setup can write them

## .the defect

`~/.claude/settings.json` on this laptop holds hooks that rhachet roles authored for a REPO. they ran
in every session on this machine, from every repo, the commander's included, and they block his
sprouts. measured 2026-10-20, a read of the file:

- `repo=bhrain/role=learner`: PreToolUse `Write|Edit|Bash` → `./node_modules/.bin/rhx memory.guard --mode hook`
- `repo=bhrain/role=driver`: route.drive, route.bounce, route.mutate.guard, route.foreground.guard
- `repo=ehmpathy/role=mechanic`: every pretooluse forbid, check-permissions, notify-permissions
- `repo=bhuild/role=behaver`: the sessionstart boot-behavior hook
- `repo=bhuild/role=dispatcher`: radioTaskHeld on Stop

the likely writer: the published adapter `rhachet-brains-anthropic@0.4.3` writes a repo's
`.claude/settings.json` by name, and where that file is an arrow to the home file, the write lands
in home scope. a separate rhachet tree cures the writer. this tree is the guard.

## .the want

1. **stripped**: every role-authored hook leaves `~/.claude/settings.json`. every key that is not a
   role hook stays exactly as it is: env, model, permissions (defaultMode and the rest), and all others.
   those are the commander's
2. **locked**: the file is read-only by default. dev-env-setup is its one owner
3. **an unlock path** exists that only dev-env-setup's own skill uses, to change the file on purpose
   and lock it again
4. **proven**: a clamp test shows that a write from outside dev-env-setup fails loud, red without the
   lock and green with it

## .how it runs (the commander's order, via the surdirector)

- this tree is LOCAL on purpose: the target is this laptop's own home, so the apply runs here
- the skill runs **plan first**, then **apply**, and keeps a backup of `~/.claude/settings.json`
  beside it before any write
- if the harness refuses the apply, do NOT reshape it. stop, and report the exact skill command up.
  the director carries it to the commander
- after apply, report a read of the file that shows zero role hooks remain and that the file is locked

## .bounds

- **open hours: no commits and no radio pushes** until the director says they have closed. build,
  test, and apply locally. where a stone asks for a commit, halt there and report
- this tree releases as a pair with `rhachet.beav.fix-enroll-never-writes-home-scope`. neither ships alone
