# 1.vision.experience.dimensions

## .the axes

| axis | values | orthogonal because |
|---|---|---|
| **operation** — what touches the home file | `plan` · `apply` · `read` (a claude session loads the file and runs its hooks — the consumer, where the harm lands) · `foreign open` (a writer opens the path in place: a sprout's boot writer, claude's own save, an editor) · `foreign rename` (a writer renames a tmp onto the resolved path) | it names the ACT. every act can meet every file state below; no state implies an act |
| **write bit** | `writable` · `locked` | a mode bit; independent of content |
| **role hooks** | `present` · `absent` | content; a locked file can hold them (a hand unlock let a writer land) and a writable one can lack them |
| **patch** | `current` · `stale` | content; whether the 5.3.brains keys hold their declared values, independent of hooks and mode |

plus one sentinel: the file **absent**, where the three state axes do not apply.

⇒ the product: 5 operations × (2 × 2 × 2 + 1) states = **45 cells**, every one verdicted in `case=_`.

## .what is NOT an axis, and why

| candidate | why it is folded, not crossed |
|---|---|
| `mode: plan · apply` (prior draft) | fused into `operation` — a mode is a property of the owner's act only. a foreign writer has no mode, so a separate axis made whole rows impossible |
| `actor` (prior draft) | split: the owner's acts are `plan`/`apply`; every other actor reduces to HOW it writes (`open` vs `rename`), which is the only fact the lock's outcome depends on |
| `run end: completes · dies` | a property of `apply` only (plan writes naught; a foreign writer's crash is not this tree's). verdicted as sub-cells of `apply`, not crossed |
| `concurrency: alone · in a race with a foreign writer` | same — a property of `apply` only. sub-cells of `apply` |
| `session: bare · enrolled` | a property of `read` only — it decides what a home role hook does to the session (runs foreign gates vs runs a repo's own gates twice), never what the file holds. sub-rows of `read` |
| `apply terminal: locked · writable + stripped` | an OUTCOME of `apply`, not an input — the boot gate picks it. the second is the fail-safe; verdicted as an `apply` sub-cell |
| `arrow: present · severed` | decides whether a foreign writer reaches home at all. severed ⇒ the write lands in-tree and home is untouched, in every state. one row in `case=_`, not a cross |

## .nature-impossible pairs

none remain in the 45 — the fold above removed every pair that cannot occur (a foreign writer in `plan` mode, a hand edit that dies mid-apply). those are recorded in the table above instead of left silent.

## .nurture-forbidden cells — the invariants

| cells | why barred | held by |
|---|---|---|
| `foreign open × L` (4 content states) | the `0444` mode refuses an in-place open for write. invariant: **while locked, a foreign open gets `EACCES` and home stays byte-equal** | case 2, case 7, the clamp's green arm |
| `read × H`, after any apply | the strip leaves zero `repo=*` hooks, and apply is the one writer. invariant: **after apply, a session that reads home runs no role hook** | case 8, verify |

`foreign rename × L` is **not** forbidden: a rename succeeds past `0444`. it stays itemized as F1's
open risk, detected by the next plan.
