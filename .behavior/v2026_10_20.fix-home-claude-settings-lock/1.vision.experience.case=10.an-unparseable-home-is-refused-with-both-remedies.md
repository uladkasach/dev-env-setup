# case 10 — an unparseable home is refused, untouched, with both remedies

## .narrative

a box's `~/.claude/settings.json` holds a half-written document — `{ broken` — the state measured
on a real rebuild. the apply cannot strip what jq cannot read, and a rewrite would destroy the
commander's keys. so it refuses: the file stays byte-equal, no backup and no candidate are left
beside it, and the verdict names the two ways out — repair the file by hand, or move it aside so
the next apply writes the patch whole.

## .bdd

```
given a home settings file whose content is not json
when [t0] rhx grove.provision --what 5.3.brains --mode apply
  then ✋ with its cause, and both remedies named
  then the file is byte-equal; no backup; no tmp
when [t1] rhx grove.provision --what 5.3.brains   (plan)
  then ✋ "hooks uncounted" — never ✔
when [t2] the human moves the file aside, then applies
  then the patch is written whole, in the declared mode
```
