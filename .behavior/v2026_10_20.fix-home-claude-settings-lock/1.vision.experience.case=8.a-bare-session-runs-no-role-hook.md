# case 8 — a bare session runs no role hook

the harm the wish exists to cure, and its cure, from the consumer's seat.

before: the commander opens a bare `claude` in a scratch dir with no rhachet roles. claude loads
`~/.claude/settings.json` and runs every hook in it. `route.drive` prints a route that is not his;
`check-permissions` blocks his `ls`; `memory.guard` calls a `node_modules/.bin/rhx` that is not
there and errors on every write. he never enrolled a role here, yet every role's gate is on him.

after: the same session loads the same file and runs only the hooks he wrote himself. his `env`,
`model`, and `permissions` still apply. an enrolled session in a rhachet repo still gets its role
hooks, from that repo's own `settings.of.repo.json` via `--settings`, not from home.

the lock does not touch this read: a read never needs the write bit. so the outcome turns on one
axis only, `role hooks`.

```
given [c8.a] home settings hold 22 role hooks (the before)
  when [t0] a bare claude session starts in a dir with no rhachet roles, and runs `ls`
    then the route.drive boot prints a route that is not the commander's
    then check-permissions blocks `ls` with "✋ ConstraintError: this command is not paved"
    then each write prints memory.guard's error for an absent node_modules/.bin/rhx

given [c8.b] home settings hold zero role hooks (after apply)
  when [t0] the same session starts and runs `ls`
    then no hook with author repo=* fires
    then `ls` runs; env, model, and permissions read as the commander set them
  when [t1] an enrolled session starts in a rhachet repo
    then that repo's role hooks fire, loaded from its settings.of.repo.json

given [c8.c] the lock declared off (the shipped value), an apply, then a pre-shield install
  when [t0] that install's init writes its hooks through the arrow
    then the write lands — no lock, by declaration; no writer re-strips between applies
    then the next bare session runs those hooks again: [c8.a] returns until the next apply
  when [t1] rhx grove.provision --what 5.3.brains --mode plan
    then ✋ role hooks, one row per author — the one detector
  when [t2] rhx grove.provision --what 5.3.brains --mode apply
    then the hooks are stripped; [c8.b] holds again
```

⚠️ [c8.b] holds for good only under `on`. under the shipped `off` it holds from one apply until the
first pre-shield install after it ([c8.c]); clamp arm 22g proves that window.
