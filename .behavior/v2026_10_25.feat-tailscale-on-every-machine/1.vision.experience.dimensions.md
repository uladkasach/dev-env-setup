# 1.vision.experience.dimensions — 5.23.tailscale + the hetzner probe

## .the dimensions

each axis is one concept, and no value on one implies a value on another.

| axis | values | why it is its own axis |
|---|---|---|
| box | laptop · ec2 grove · hetzner box | decides the tier the box reads, so which join is legal |
| root | the seat holds root · it does not | decides whether a box-wide write may happen |
| seat | a human at the laptop's own keyboard · a human over ssh · no human (a cron, a unit) | decides whether a member join may mint a url, and whether a person can open it |
| install | absent, served key matches the pin · absent, served key differs · source declared, package absent · present, signed source · present, other source | decides the provision work owed, and whether the trust anchor holds |
| daemon | not joined (`NeedsLogin`, `NoState`) · joined (`Running`) · taken down (`Stopped`) · not settled (`Starting`) · held by another login (`InUseOtherUser`) · awaits approval (`NeedsMachineAuth`) · unreadable | decides the configure work owed. every value but the first takes no `up` |
| mode | plan · apply | decides whether any write may happen at all |
| concurrency | alone · a second apply while the first holds apt · a second apply while the first is at the join | the race the "one join per machine" guard must survive |

⚠️ **the probe fact is a sub-type of the hetzner box, not an axis.** a hetzner box has its
bootstrap fact on disk, lacks it, or holds it unreadable; a laptop and an ec2 grove carry no such
fact at all. so it splits only the `hetzner` value: present · absent (C3) · unreadable (C4).

⚠️ **a joined node carries three sub-types, not axes.** each exists only where `daemon = joined`:

| sub-type | values | read by |
|---|---|---|
| tags | none · exactly `tag:camp` · another set | every box (C5, C6) |
| camp peer | a camp grove is a peer · none is | the laptop (C5) |
| shields | up · down · unreadable | the laptop (C5) — a laptop reaches out and is never reached in |

⚠️ **a cloud box takes no join here at all.** its provisioner joins it as `tag:camp`, and this
bundle only verifies the result (seed S005, F003). so a cloud box carries no tagged key, and no
cell of this bundle reads or writes one.

⚠️ **the url is a transition between two runs, not an axis.** a url prints only on a cell that
reaches C17. whether the human opens it decides the NEXT run's `daemon`: opened → `joined`, left
unopened → `not joined` again, and verify shows the url the daemon holds, or names the rerun that
mints one when it holds none. case 1 demos the open, case 4 the unopened.

## .the walk — two ordered partitions, one per phase

a run passes two phases, so every cell of the product gets exactly one **provision** verdict and
exactly one **configure** verdict. within each phase the rules run top to bottom and the first match
wins. each phase ends on rules that between them match every cell left (P8 after P4 has removed
`root = no`; C15, C16 and C17 split the laptop on `seat`), so no cell is left with no verdict in
either phase.

### provision

| rule | when the cell has… | verdict | boundary |
|---|---|---|---|
| P1 | mode = plan | no upsert; verify reports the install state | B8 |
| P2 | concurrency = a second apply while the first holds apt | the second apply waits on the dpkg lock, or ✋s that apt is busy and names the rerun | B12 |
| P3 | install = present, signed source | `already installed — no work` | B14 |
| P4 | root = no | 🌙 decline; prints `sudo -v && rhx grove.provision --what 5.23.tailscale --mode apply`; verify ✋ absent | B1 |
| P5 | install = absent, key differs | ✋ refuse; no file lands; verify ✋ absent | B2 |
| P6 | install = absent, key matches | declare the source, refresh apt, install + enable | B3 |
| P7 | install = source declared, package absent | refresh apt, then install + enable | B3 |
| P8 | install = present, other source | declare the signed source; no reinstall (F010) | B9 |

| rule | when the cell has… | verdict | boundary |
|---|---|---|---|

## .C3 — the impossible cell

a hetzner box whose bootstrap fact is absent (a fresh box, a bootstrap that never ran) answers no
rung of the probe ladder: no ec2 fact, no `/etc/grove/platform`, no desktop. `grove.env.sh` has no
fallback, so it refuses the run with exit 2 and names the fix: the bootstrap's
`/etc/grove/platform`, or `GROVE_ENV_SERVER=cloud@hetzner.hetzbot`. no bundle runs, so no member
join can. the derivation holds the invariant, and a second guard on a `camper` seat would only
risk a block on a laptop that hosts a local seat (F011, dropped).

C4 is its twin: the file is there and unreadable. read as "absent", a box with a forwarded
display would reach the desktop rung and read `local@unix`, so the derivation halts instead.

## .the derivation's other refusals

`grove_for_detect` answers empty, never `local`, for a set-but-malformed server value (`notatier`)
and for an unset value whose derivation halts (C3, C4). each is a refusal of the run, never a
guess (`prove.for-detect-refuses-an-underived-env`). they sit outside the product above: no bundle
runs on them.

## .forbidden cells

- **forbidden:** a member join on any box that reads `cloud@*` (C6, C12); an unnamed or unreadable
  box never runs at all (C3, C4) — the invariant "a remote grove never joins as a member"
- **forbidden:** `--advertise-tags` or `--auth-key` anywhere in this bundle — a laptop must never
  take `tag:camp`, and a grove's tagged join belongs to its provisioner (B7, B15)
- **forbidden:** a member join from a remote seat (C15) — a url minted over ssh puts the human's
  login on whatever box the shell reached
- **forbidden:** a sign-in by a seat with no root (P4, C13) — the sign-in is the human's act
- **forbidden:** shields reported up when they could not be read (C5) — an unread shield is a 💥
- **forbidden:** a non-apt box — `pkg_assert_apt` refuses with a ✋; the wish is ubuntu only. the
  actor can attempt it, and the behavior rejects it, so it is a rejection invariant, not an
  impossibility
