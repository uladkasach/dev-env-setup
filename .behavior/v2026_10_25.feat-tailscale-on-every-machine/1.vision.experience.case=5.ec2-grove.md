# case 5 — an ec2 grove, joined by its provisioner, verified here

## .narrative

infra's provisioner builds a fresh ec2 grove: it installs tailscale and joins the box as
`tag:camp`, as root, before any seat runs. a crew member then opens the grove's `ground` seat and
runs the tree apply. the tailscale bundle writes naught: it finds the client in place and the node
joined, and says so in one `no join owed` line. verify reads ✔ joined · tags = tag:camp. the
`camper` seat runs the tree next and sees the same two lines. no url, no prompt, no key on the box.

## .timeline

```
given an ec2 grove (`cloud@aws.ec2`) its provisioner joined as tag:camp
  when [t0] the crew runs `rhx grove.provision --mode apply` as `ground`
    then the run's header reads `cloud@aws.ec2`; the hetzner probe answers no here           # B11
     and provision.verify finds tailscale present; no apt source of this repo is judged      # B15
     and configure.upsert `this node already joined the tailnet — no join owed`               # B5 (C6)
     and it makes no `up` call, and reads no key                                             # B4 B15
     and configure.verify ✔ joined · tags = tag:camp (a tagged node has no user login)      # B16 (C6)
  when [t1] the crew runs the tree apply as `camper`
    then they see the same `no join owed` and the same ✔
```

## .fail-safe

a member join is unreachable here: the tier routes a cloud box away from the member path, and this
bundle carries no `up` for a cloud box at all. verify ✋s a user login on a cloud box (the breach)
and any tag set other than exactly `tag:camp`.
