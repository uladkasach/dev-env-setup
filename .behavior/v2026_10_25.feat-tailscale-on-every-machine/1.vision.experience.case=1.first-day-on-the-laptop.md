# case 1 — the commander's first day on the laptop (dense)

## .narrative

the crew picks up #174 and runs the bundle from its agent shell. it gets a 🌙: tailscale is
box-wide, this seat has no root, and here is the one line the human owes. the commander pastes
`sudo -v && rhx grove.provision --what 5.23.tailscale --mode apply` into his own terminal. the key
verifies, the package lands, tailscaled starts. a login url prints, with the same line to rerun, and
the run ends; verify ✋s that the sign-in is owed. he opens the url and signs in as himself. he
reruns the line: `no work`, `no join owed`, shields up, and ✔ joined as a member, no tags, a camp grove in sight.
`ssh camper@<host>` connects. that night the full tree apply passes the bundle without a word.

## .timeline

```
given a pop-os laptop with no tailscale, and the commander at his terminal
  when [t0] the agent shell runs `rhx grove.provision --what 5.23.tailscale --mode apply`
    then provision.upsert 🌙 declines: box-wide, no root                                    # B1
     and it prints: sudo -v && rhx grove.provision --what 5.23.tailscale --mode apply
     and provision.verify ✋ tailscale absent, with the same line
  when [t1] the commander runs that line himself
    then the key verifies against its pin, the source is declared, tailscale installs       # B2 B3
     and tailscaled is enabled and active
     and configure.upsert reads `local@unix`, not joined → the member join is legal         # B4
     and a login url prints, with the rerun line, and the run exits                         # B6
     and configure.verify ✋ not joined — the daemon reads NeedsLogin; the sign-in is owed
  when [t2] he opens the url and signs in as himself
    then his browser shows the laptop added to the tailnet under his own login
     and the node is now a member — the next run reads `daemon = joined`
  when [t3] he reruns the line
    then provision.upsert prints `tailscale already installed — no work`                              # B14
     and configure.upsert prints `this node already joined the tailnet — no join owed`, then `shields up — this laptop refuses inbound tailnet traffic ✔`                       # B5
     and configure.verify ✔ joined as a member · no tags · shields up · a camp grove is a peer             # B7 B10 B17
  when [t4] he runs `ssh camper@<host>`
    then it connects (the acl and the grove are ahbode/infrastructure's)
  when [t5] the full tree apply runs that night
    then 5.23.tailscale writes naught and asks naught                           # B14 B5
```
