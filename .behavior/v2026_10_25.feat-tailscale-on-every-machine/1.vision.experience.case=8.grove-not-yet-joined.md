# case 8 — a grove its provisioner has not joined yet (sharp, fails safe)

## .narrative

the commander's new hetzner box has its bootstrap fact, so it reads `cloud@hetzner.hetzbot`, but its
provisioner's join has not run yet. the crew runs the tree as `ground`. where a joined grove shows
`no join owed`, they see a 🌙: a grove is joined by its provisioner, never here. then verify ✋s:
not joined, and it names the provisioner's two steps — mint a tagged key for this grove, then the
provision path's join as root with `--advertise-tags=tag:camp`. the bundle does not try a member
join, and asks for no key. infra runs its join; the crew reruns; verify ✔ joined · tags = tag:camp.

## .timeline

```
given a hetzner box with its probe fact, not joined (`NeedsLogin`)
  when [t0] the crew runs `rhx grove.provision --mode apply` as `ground`
    then configure.upsert 🌙 a grove is joined by its provisioner, never here               # B15 (C12)
     and it makes no `up` call, offers no url, and reads no key                              # B4
     and configure.verify ✋ not joined — the daemon reads 'NeedsLogin'
     and it names the provisioner's join (ahbode/infrastructure): the key mint for this
         grove, then the provision path's join, as root, with --advertise-tags=tag:camp
  when [t1] infra's provisioner runs that join
    then the node is tagged `tag:camp`
  when [t2] the crew reruns the apply as `ground`
    then configure.upsert `this node already joined the tailnet — no join owed`               # B5 (C6)
     and configure.verify ✔ joined · tags = tag:camp                                         # B16
```

on an ec2 grove the same 🌙 and ✋ print; the provisioner is the same, and so is its handoff.

## .fail-safe

no fallback to a member join (the remote invariant holds while the grove waits), loud (a ✋ on
every apply until joined), teaches the fix (the provisioner's two steps, with the owner named).
