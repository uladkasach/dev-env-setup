# case=4 — the camper picks up its AWS badge, with no human and no IMDS

covers inventory rows 21, 22, 23, 24, 30, 31. feel: 😊 happy at the center, 🗡️ sharp at four
edges. care: 🔴 critipath — this is the whole gap the wish names.

## .narrative

a crew on `house-1` runs the integration suite — the identical command a laptop and grove-1
type:

```
rhx git.repo.test --what integration
```

the suite reads `ahbode.test.AWS_PROFILE` off the rack, gets `ahbode.test.ehmpath`, and the sdk
reads `~/.aws/config`. on grove-1 that profile says *assume the prep role, from the instance
role*. on house-1 it says *assume the prep role, from `ambient`* — and `ambient` is the one
block that differs:

```ini
# grove: the ambient badge — begin
[profile ambient]
credential_process = aws_signing_helper credential-process --certificate ~/.aws/house/cert.pem --private-key ~/.aws/house/key.pem --trust-anchor-arn <ta-arn> --profile-arn <ra-profile-arn> --role-arn <house-role-arn>
region = us-east-1

[default]
credential_process = …same…
region = us-east-1
# grove: end

# grove: reach ahbode.test.ehmpath — begin
[profile ahbode.test.ehmpath]
role_arn = arn:aws:iam::<prep-acct>:role/<prep-oidc-role>
source_profile = ambient
region = us-east-1
# grove: reach ahbode.test.ehmpath — end
```

the cert and key sit in the camper's home, mode 0600, under a 0700 dir. no other unprivileged
uid on the box can read them — not house-2's camper, not the supervisor. root can, and so can
any seat that holds sudo: the wall stops other users, never root. within that bound, the AWS
boundary the wish hoped for is a fact the verify CHECKS, not one it assumes.

the edges each fail loud. a cert past its life: the sts error is caught and re-told as *"the
house badge cert expired at <ts>; renewal owes …"*. a key someone widened to 0644: the verify
refuses with ✋ before any call, since a world-readable key IS the EC2 hole again. and before
`ahbode/infrastructure#36` lands a trust anchor, there is no cert at all — the verify says so
by name, and points at #36, rather than paper over it.

## .timeline (sketch)

```ts
given('[case4] house-1 converged; #36 has placed a trust anchor + a role for house groves', () => {
  when('[t0] camper runs a bare `aws sts get-caller-identity` (no profile named)', () => {
    then('[default] answers via credential_process: the house role, in the camp account');
  });
  when('[t1] camper runs it with --profile ahbode.test.ehmpath', () => {
    then('the hop lands in <prep-acct> — the same account grove-1 lands in');
    then('aws.reach.set wrote source_profile=ambient, never credential_source=Ec2InstanceMetadata');
  });
  when('[t2] camper runs `rhx git.repo.test --what integration`', () => {
    then('the suite lands where a laptop\'s and grove-1\'s land (rule.require.identical-commands-on-every-server)');
  });
  when('[t3] the cert has expired', () => {
    then('the badge call fails, and the verify names the expiry time and the renewal');
  });
  when('[t4] the key mode is widened to 0644', () => {
    then('5.6.aws verify fails ✋ before any aws call: a readable key is no boundary');
  });
  when('[t5] #36 has not landed: no trust anchor, no cert', () => {
    then('5.6.aws on a house seat reports ✋ "no house badge yet", names ahbode/infrastructure#36');
    then('it never falls back to sso, a static key, or a serve endpoint');
  });
  when('[t6] supervisor runs `git.grove.send house-1 --reply --play prove.grove-aws-identity-chain`', () => {
    then('the play asks a consumer\'s questions: bare call → region + badge; rack name → profile → sts');
    then('it exits 0 on house-1 and on grove-1 alike');
  });
});
```
