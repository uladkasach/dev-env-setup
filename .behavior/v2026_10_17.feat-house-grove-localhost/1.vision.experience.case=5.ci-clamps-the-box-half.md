# case=5 — ci mints, reaches, probes, and tears down a house grove on every push

covers inventory rows 7, 33, 34, 40. feel: 😊 happy, one 🗡️ seam. care: 🔴 critipath — the
wish names a clamp that runs in ci, and a house grove is the first grove a ci runner CAN be.

## .narrative

a github runner is a fresh ubuntu box with passwordless sudo and no human. that is exactly a
host that can mint a house grove for real — no mock of `useradd`, no fake sshd.

the job mints `house-ci`, pushes the checkout into each seat, and converges only the
house-specific pieces in each — the `<n>.house` host bundle, and a narrow
`grove.provision --what <slug>` that makes the seat derive its env and write its badge profile.
never the full bundle tree: a full converge installs every package the laptop holds, which a ci
job pays for in minutes and which proves naught about a house grove. it then sends a reply
through loopback ssh and runs the boundary probes: the camper of `house-ci` cannot read
the runner user's home; the runner cannot read the camper's `~/.aws/house/`; no process on the
box answers on an IMDS-shaped port. then it deletes the grove and checks that every user, unit,
and registry row is gone.

the one fact a runner cannot hold is a real trust anchor — that needs #36 and an account. so
the ci job runs `prove.house-grove-box-half`, which asserts every fact that stops at the box,
includes the badge profile's SHAPE and its file modes, and stops there by declaration. the AWS
half is `prove.grove-aws-identity-chain`, run on the human's box where the trust exists. the
split is two named plays, never one play that skips a rung when a secret is absent.

## .timeline (sketch)

```ts
given('[case5] a fresh github runner, sudo -n works, no human', () => {
  when('[t0] job runs `rhx git.grove.house.set house-ci --mode apply`', () => {
    then('both seats + the loopback unit + both registry rows exist, as in case=1');
  });
  when('[t1] job runs a narrow `grove.provision --what <house-specific slugs>` in each seat, GROVE_ENV_SERVER derived (not set)', () => {
    then('both runs derive house@unix by the marker — the probe itself is under test');
    then('no slug outside the house-specific set runs; the job never converges the full tree (ruled, seed S1)');
  });
  when('[t2] job runs `prove.house-grove-box-half` via `git.grove.send house-ci --reply --play`', () => {
    then('loopback reply works into the camper seat');
    then('a runner has no yubikey, so ground authorizes a throwaway key the job mints and shreds; the summary says so (F12)');
    then('`ss -tln` shows the loopback house port and no :22 (F4)');
    then('[profile ambient] is credential_process; no Ec2InstanceMetadata line; no serve endpoint on any port');
    then('cross-uid reads are refused both ways');
    then('aws.params gates fail closed');
  });
  when('[t3] the AWS half', () => {
    then('ci does NOT run prove.grove-aws-identity-chain — it is a separate play, run where #36 trust exists');
    then('the job summary names that split in one line, so a green job is never read as "the badge works"');
  });
  when('[t4] job runs `rhx git.grove.house.del house-ci --mode apply`', () => {
    then('users, homes, unit, sshd allowance, registry rows: all absent');
    then('a second del reports `•` and exits 0');
  });
});
```
