# case=2 — each seat converges, and knows it is a house seat

covers inventory rows 9, 10, 11, 12. feel: 😊 happy, with two 🗡️ sharp edges that exist TODAY.
care: 🔴 critipath — a seat that misreads its own kind either halts or opens a prompt onto a
duct.

## .narrative

the supervisor drives the convergence the way it drives an EC2 grove: push the worktree to the
ground seat, apply; then the camper seat, apply. ground first, because camper's home bundles
want what the system half installs.

each run's header reads `server house@unix`. so the bundles that need a screen decline with
their usual 🌙, the bundles that read `local@unix` as "a human is at a keyboard" stay shut, and
`5.12.rack`'s `*@aws.ec2` gate fails closed — no `aws.params` read or write on a box that is not
ec2 (`rule.forbid.aws-params-off-ec2`). the system half on ground mostly reads `•`: the host's
own `local@unix` run already put those packages down, on the same disk.

what happens today, on this same box, is the reason the case exists. a login over loopback has
no DISPLAY, no "Amazon EC2" in dmi, and no IMDS — so `grove_env_derive` answers no probe and
halts with *"cannot tell which machine this is"*. and worse: if the human's ssh forwarded a
DISPLAY, the desktop probe would fire and the seat would call itself `local@unix` — a laptop
with a human at it.

so the house rung runs FIRST, and it reads a declared fact, not a guess: the mint wrote a
marker the seat can read and cannot write.

## .timeline (sketch)

```ts
given('[case2] house-1 minted (case=1), worktree pushed to both seats', () => {
  when('[t0] ground seat runs grove.provision --mode apply', () => {
    then('the header reads `server house@unix`');
    then('screen bundles (4.3 kitty, 6.* apps, 3.* cosmic) decline 🌙, each beside its reason');
    then('5.12.rack declines its ssm read: house@unix is not *@aws.ec2');
    then('2.3.ssh does not unmask ssh.service — the house sshd is a separate unit');
    then('box-wide facts the host already set read `•`, not a second write');
  });
  when('[t1] camper seat runs grove.provision --mode apply', () => {
    then('the header reads `server house@unix`');
    then('box-wide steps decline via bundle.root.declines, as on an EC2 camper');
    then('5.6.aws writes [profile ambient] with credential_process (case=4), never Ec2InstanceMetadata');
  });
  when('[t2] TODAY, before the house rung: a seat derives its server over loopback', () => {
    then('no probe answers → `✋ cannot tell which machine this is` (the extant halt)');
    then('with a forwarded DISPLAY → the desktop probe answers local@unix — the dangerous misread');
    then('⇒ the house probe must run before the desktop probe, and read the mint\'s marker');
  });
  when('[t3] a camper tries to write the marker itself', () => {
    then('refused: the marker is root-owned, mode 0644, outside the seat\'s home');
  });
});
```
