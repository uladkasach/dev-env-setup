# 1.vision — the first house grove, on the box the supervisor runs on

## .the outcome world

### a day with it in place

the human's laptop runs the supervisor, as it does today. beside it, invisible on the desktop, sit
two more unix users — `house-1-camper` and `house-1-ground` — reachable only over loopback.

at 22:00 the supervisor dispatches a crew to `house-1` with the same verbs it uses for grove-1.
the crew runs `rhx git.repo.test --what integration`; its AWS calls land in the prep account,
the same account grove-1's land in. at 10:00 the session it started with has expired twice
over; the crew never noticed. no one unlocked a keyrack, opened a browser, or touched a key.

the wish measures that over days, not one run, so case=7 walks a week: nights, a reboot, a lid
close, and the cert's own 7-day renewal, all with no human.

on every push, ci mints a house grove on a fresh runner, converges only its house-specific
pieces (never the full tree), reaches it, probes its walls, and tears it down. the box half of every grove change is proven before a human looks.

### before → after

| | before | after |
|---|---|---|
| the cheapest grove | an EC2 box, ~$385/mo | a second user on a box already owned, ~$0 marginal |
| a new grove | infra mints it from userdata, hours | `sudo -v && rhx git.grove.house.set house-1 --mode apply`, seconds |
| a loopback login converges | halts: *"cannot tell which machine this is"* | `server house@unix`, by a declared marker |
| the AWS badge off EC2 | none — sso needs a browser, IMDS needs EC2 | `credential_process` over a cert no other unprivileged user can read |
| a second unprivileged uid on the box | reads the full badge (IMDS) | reads none — a file mode, checked on every converge. root, and any seat with sudo, still can |
| grove changes in ci | none; plays run by hand on a remote box | a real grove, minted and torn down per push |

### the aha

on EC2 the OS boundary buys no AWS boundary — every uid curls the badge. **on a house grove the
badge is a file, and a file has an owner.** so the cheapest grove is also the first one whose
AWS badge is walled off from the other users on its box. the wall stops other users, never root:
root, and any seat that holds sudo, can read the cert. and because the whole grove lives on one machine, it is the first grove
ci can build for real.

## .the contract — sketch, not committed

```sh
# mint (human, root, once)                         → case=1
#   writes ONE election file, then drives the host bundle through the one door (F11):
#   grove.provision --what <n>.house --mode apply
sudo -v && rhx git.grove.house.set house-1 --mode apply
sudo -v && rhx git.grove.house.del house-1 --mode apply

# converge (each seat, ground first)                → case=2
rhx git.grove.push house-1.ground --from . --into git/more/dev-env-setup --mode apply
rhx git.grove.send house-1.ground --detach --what 'bash $HOME/git/more/dev-env-setup/src/grove.provision._.sh --mode apply'
#   …then the same for house-1

# reach + prove (supervisor, no tty)                → case=3, case=4
rhx git.grove.send house-1 --reply --what whoami
rhx git.grove.ready.verify house-1
rhx git.grove.send house-1 --reply --play prove.grove-aws-identity-chain
```

| fact | value |
|---|---|
| the uri | `house://house-1` — the grove name, never `localhost` (F1) |
| the box state | a host bundle `<n>.house` converges every declared house grove: users, slice caps, sshd unit, sudoers — F11 |
| the registry row | `~/.git.forest/groves/house-1.json`, `type: house`, `at: house-1-camper@127.0.0.1:<port>` |
| the seats | `house-1-camper` (no sudo; a key file the supervisor holds) · `house-1-ground` (NOPASSWD; the human's yubikey key, a touch per use) — F2, F3, F12, F14 |
| the reach | `grove-house-sshd.service` on 127.0.0.1 only, its own config; `ssh.service` + `ssh.socket` masked BEFORE `openssh-server` lands — F4 |
| the env | `$GROVE_ENV_SERVER = house@unix`, from a root-owned marker, probed first — F5 |
| the badge | `[profile ambient]` = `credential_process = aws_signing_helper credential-process …`; reach profiles use `source_profile = ambient` — F6 |
| the clamp | `prove.house-grove-box-half` in ci; `prove.grove-aws-identity-chain` on the box — F7, F9 |

## .mental model

- **to a friend:** *"a guest account on my laptop that the robots work in. it has its own aws
  key that only it can read, so they can run all night and can't touch my stuff."*
- **analogy:** a granny flat. same lot, same utilities, its own door and its own lock. the
  landlord (ground) holds a master key; the tenant (camper) holds only theirs.
- **their words vs ours:**

| a human says | we say | why ours |
|---|---|---|
| guest account, sandbox user | seat | a seat is account + reach + powers (`term=seat`) |
| the vm on my laptop | house grove | no vm — two users on the host kernel; `house` is #130's tier |
| its aws login | the badge, `ambient` | `term=ambient`: the box's own identity, before any hop |
| ssh to localhost | reach over loopback | the uri names the grove, never the host (F1) |

## .evaluation

### against the wish's goals

| goal | verdict |
|---|---|
| a second unix user with its own camper + ground | ✔ case=1 — both seats kept (F14, best guess) |
| reached over loopback ssh | ✔ case=3 |
| an AWS identity with no human in the refresh loop | ✔ on the box half (case=4, case=7); **the trust anchor is #36's** (F13) |
| passes `prove.grove-aws-identity-chain` | ✔ once that play exists — it does not yet (F9) |
| a clamp that runs in ci | ✔ the box half in ci; the identity play on the box (F7, ruled by the director, seed S1) |
| the authority form proposed and recorded | ✔ F1 |
| reach from a supervisor off the LAN; survive a lid close | not this stone's — both bind the remote laptop (ruled, seed S1) |

### pros
- the cheapest possible grove, and the test bed for every later grove — ci can mint one
- an AWS badge walled off from the box's other users — not from root — verified on every
  converge. EC2 cannot hold even that much
- consumers change in zero places: `ambient` swaps its source; every hop keeps its shape
- the 2026-09-03 sshd invariant stays intact

### cons
- it shares the laptop's kernel, RAM, and disk with the human. a per-seat slice pages the crew
  to swap first and kills only a true runaway, inside the grove (case=9, F10) — the wish's swap
  cushion, kept. disk and cpu stay shared
- the ground seat is root of the human's laptop (F3, kept per F14); a yubikey touch gates it (F12)
- a copied cert works off the box for up to its lifetime (7 days), longer than EC2's
  hours-long sessions. recorded and accepted here; a hardware-held key is a one-line swap (F15)
- one external dependency (#36) gates the badge; until it lands the house grove is a grove
  with no AWS reach, and says so

### edges, and how the contract keeps a pit of success

| edge | the guard |
|---|---|
| a house seat misreads itself as `local@unix` | the house probe runs first, off a root-owned marker (case=2) |
| a bare `rhx …` mint with no tty | declines before any write; prints the `sudo -v &&` line (case=1) |
| the camper key or cert is widened | the verify refuses ✋ before any aws call (case=4) |
| the camper's cert and key are copied off the box | a copy needs the camper uid, root, or a sudo seat; it works for up to the cert's life. recorded, not walled (F15) |
| someone swaps to `serve` "for speed" | the verify refuses the profile shape (case=6) |
| the cert nears its end | a renewal timer, and a verify that reports hours-left days ahead (case=7) |
| the laptop reboots mid-week | the house sshd unit is enabled and returns with the box; the cert is a file, so no badge restart (case=7 `[t1]`) |
| the lid closes, or the box idles to suspend, mid-crew | binds naught here — the whole box sleeps and wakes as one; the crew resumes and its next aws call re-signs (case=7 `[t4]`). lid-close survival binds the remote laptop |
| the wifi idles or stalls | binds naught here — the reach is loopback, so it never drops; aws calls resume once the host's `1.11.wifi` watchdog reconnects (case=7 `[t4]`) |
| the LAN dials the house port | loopback only (case=3) |
| the house ground rewrites a box-wide fact the host holds | it declines 🌙 and names the host as owner; a house seat adds, never rewrites (case=8) |
| a crew process exhausts the laptop's RAM | the house slice pages first; a backstop kill lands inside the seat's slice only (case=9) |
| a later edit hand-writes a house user or sshd unit | the box state is a bundle's; its verify reports the drift, and a re-apply converges it (F11) |
| `del --orphaned` deletes a live house row | the row carries `type: house` and no exid, so the extant skip at `:3205` holds (case=3) |
| a duct to `localhost` lands in the wrong tmux | the authority is a grove name, never `localhost` (F1) |

## .what is awkward

- **`localhost` was the obvious name, and it is the one name that cannot work.** the wish
  itself reaches for `house://localhost`; F1 replaces it, and the peers must agree
- **the ground seat is root of the human's own laptop.** identical composition says yes; the
  blast radius says think twice. F3 is the least comfortable call here
- **the box half ships before the badge can.** a house grove minted before #36 lands is a
  grove that converges, reaches, and passes every box check — and has no AWS reach. that is
  honest, and named, but it is half a grove
- **two plays where the wish named one.** F7 trades a literal read of the wish for a clamp
  that never skips
- **the wish's verified-facts list held a play that never existed.** F9 corrects the premise;
  the cost estimate *"extension looks cheaper"* no longer applies
- **a shared kernel.** the house grove is a sandbox for the AWS badge and the home, not for
  memory or cpu. the wish's capacity motive is the remote laptop's to answer, not this stone's
