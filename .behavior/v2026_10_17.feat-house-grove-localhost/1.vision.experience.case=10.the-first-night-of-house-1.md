# case=10 — the first night of house-1 (the dense journey)

covers no new row. it walks rows 1, 9, 10, 13, 15, 21, 22, 31, 35, 43 in ONE realistic session,
across three actors, to exercise the boundaries together. feel: 😊 at the ends, 🗡️ in the
middle. care: 🔴 — it is the wish's whole promise, end to end.

each sharp critipath it brushes keeps its own spotlight (case=1, 4, 8, 9); this case exists for
the **interactions** — the seams no single-actor case can reach.

## .narrative

18:00. the human, at his desktop, mints the grove:

```
sudo -v && rhx git.grove.house.set house-1 --mode apply
```

two users appear, the loopback sshd unit starts, two registry rows land. he walks away.

18:05. the supervisor converges both seats over loopback — ground first, then camper. the ground
run meets `/etc` facts the laptop already set: it reads `•` on the shared ones and declines 🌙 on
the one where a grove wants a different swappiness than the laptop holds. the human's desktop is
untouched. the camper run writes `~/.aws/config` with an `ambient` that signs from the camper's
own cert.

18:10. the supervisor proves it:

```
rhx git.grove.send house-1 --reply --play prove.grove-aws-identity-chain
```

loopback → the camper seat → `credential_process` → the reach profile hop → sts in the prep
account. exit 0.

18:15–07:00. a crew runs the integration suite all night. at 01:00 one run leaks past the slice's
`MemoryHigh`; the kernel pages the house slice to swap, the run slows for an hour, and it
finishes green. the human's nvim was
open the whole time and never stalled. at 06:15 the first 12h session would have lapsed; the
next `aws` call re-signs from the cert, and the crew never notices.

07:00. the human opens the laptop to a green suite, a slow hour in `house-1`'s journal, and no prompt
anywhere.

## .the seams it exposes (why it is worth the walk)

| seam | the race or interaction | the guard it demands |
|---|---|---|
| mint → converge | the supervisor reaches the camper before the mint finished its home | the mint's last write is the registry row, so a send before it fails "no grove named house-1" (case=1 `[t0]`) |
| host converge ↔ house-ground converge | both write `/etc` the same day | a house seat adds, never rewrites (case=8) |
| crew RAM ↔ desktop RAM | the leak lands while the human is live | the house slice pages first; a backstop kill stays inside it (case=9) |
| session lapse ↔ a call in flight | the 12h edge falls inside a test | `credential_process` re-signs per call; no cached session to strand (case=7) |
| reach ↔ badge | a loopback send runs as the camper uid, so the badge it finds is the camper's own | the uid is the boundary; no env var carries it across (case=6) |

## .timeline (sketch)

```ts
given('[case10] a laptop converged as local@unix; #36 has placed a trust anchor', () => {
  when('[t0] the human mints house-1', () => {
    then('two seats, the loopback sshd unit, and two registry rows exist');
  });
  when('[t1] the supervisor converges house-1.ground, then house-1', () => {
    then('each seat reads house@unix');
    then('ground declines 🌙 on any box-wide fact the host holds at another value; the host value is unchanged');
    then('camper writes ambient with credential_process');
  });
  when('[t2] the supervisor sends prove.grove-aws-identity-chain to house-1', () => {
    then('it exits 0: loopback → camper uid → badge → hop → sts in the account asked for');
  });
  when('[t3] a crew process passes the slice\'s MemoryHigh', () => {
    then('the house slice pages to swap and the run slows, then finishes; no process dies');
    then('the human session keeps its RAM and every process');
  });
  when('[t4] 12h pass; the crew calls aws again', () => {
    then('the call succeeds with no human and no restart');
  });
  when('[t5] the host re-converges as local@unix the next day', () => {
    then('it reads `•` on every fact the house ground declined — no flip-flop');
  });
});
```
