# case=8 — the house ground meets a host fact, and defers to the host

covers inventory row 13. feel: 🗡️ sharp. care: 🔴 critipath — every converge of every house
ground would hit it, and the cost lands on the human's own laptop.

## .narrative

on EC2, the ground seat owns `/etc`: no other writer exists. on a house grove, `/etc` already
has an owner — the host's own `local@unix` run, which the human applies from his desktop seat.

so when `house-1-ground` converges, some bundles reach a box-wide fact the host already set.
where both want the same value (a package installed, a sysctl both share), the bundle reads `•`
and moves on. where they want DIFFERENT values — a bundle gated `!= local@unix` that would set
a grove's headless default where the laptop holds a desktop one — the house ground does not
write. it declines, names the host as the owner, and prints the value each side wants:

```
🌙 1.4.sysctl vm.swappiness — the host owns this box-wide fact
   ├─ host (local@unix) holds: 10
   ├─ a grove wants:           60
   └─ a house seat never rewrites the host; set it from the host seat if both should change
```

without this, the two runs would flip the fact on each converge, forever, and the laptop would
carry whichever ran last — `rule.forbid.two-writers-on-one-artifact` on the one artifact the
human cares about most.

## .timeline (sketch)

```ts
given('[case8] the host converged as local@unix; house-1 minted', () => {
  when('[t0] house-1-ground converges a box-wide fact the host already holds at the same value', () => {
    then('the bundle reads `•` — no write');
  });
  when('[t1] house-1-ground converges a box-wide fact the host holds at a DIFFERENT value', () => {
    then('it declines 🌙, names the host as owner, prints both values');
    then('the host\'s value is unchanged on disk');
  });
  when('[t2] the host re-converges after it', () => {
    then('the host reads `•` on that fact — no flip-flop');
  });
  when('[t3] house-1-ground converges a fact only a grove needs and the host lacks (e.g. a grove-only package)', () => {
    then('it installs it — additive to the host, never a rewrite');
  });
});
```

## .the rule it implies

a house seat **adds** to the host and **never rewrites** it. "a box-wide fact a house ground
may set" = one the host holds no value for. every bundle gated `!= local@unix` must be re-read
under this rule before `house@` reaches it (F5, `.what it touches`).
