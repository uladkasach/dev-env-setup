# case=9 — a house crew's hog pages and slows; the human's desktop does not

covers inventory row 43. feel: 🗡️ sharp. care: 🔴 critipath — a collocated grove shares RAM
with the human's live session, and the cost of the wrong response is the human's whole desktop,
or a crew's 17-hour work.

## .narrative

03:10. a crew on `house-1` runs a test suite that leaks; its node process climbs past 20 GB on
a 32 GB laptop. the human's desktop session — kitty, nvim, firefox, the supervisor — sits on the same
RAM.

this repo already learned two things about that moment. earlyoom, left to its own heuristics,
can kill the session rather than the hog (`gotcha.earlyoom-kills-the-session-not-the-hog`). and
on EC2, pressure kills rather than pages — a 17-hour clone lost to one SIGTERM — which the wish
asks a laptop not to repeat.

so each house seat's slice carries two values. `MemoryHigh` is the lever: past it, the kernel
reclaims and swaps from the HOUSE slice first, so the leak slows the crew and the desktop keeps
its RAM. `MemoryMax`, set well above, is the backstop: only a true runaway reaches it, and the
kill lands inside `house-1`, never in the human's session.

the next day the crew's log shows a slow hour and a finished suite; the human's session shows naught.

## .timeline (sketch)

```ts
given('[case9] house-1 minted with MemoryHigh < MemoryMax on each seat; the human\'s session live', () => {
  when('[t0] a house-1 process grows past MemoryHigh', () => {
    then('the house slice is reclaimed and paged to swap; the process slows and lives');
    then('the human\'s session slice keeps its RAM — no stall in nvim or kitty');
  });
  when('[t1] a true runaway grows past MemoryMax', () => {
    then('the kernel kills inside user-<house-1-camper uid>.slice only');
    then('no process in the human\'s session slice is killed');
    then('the oom is visible in house-1\'s journal, named by its slice');
  });
  when('[t2] the host bundle re-applies', () => {
    then('both values read `•` if unchanged; a changed declared value is applied');
  });
});
```

## .why it belongs to this stone, not the remote-laptop one

the remote laptop runs no human session to protect. the collocated grove is the one place a crew
and a human share RAM, so the cap is a property of `house://` on this box (F10).
