# case=1 — the human mints a house grove on the box they sit at

covers inventory rows 1, 2, 4, 44. feel: 😊 happy, with one 🗡️ sharp step. care: 🔴 critipath —
no house grove exists until this runs, and no other actor may run it.

## .narrative

the human sits at the laptop. the supervisor already runs here as his own user. he wants a sandbox
grove beside it — its own two seats, its own badge — so a crew can take work tonight without
the $385/mo box.

he types the mint once, as root is owed, the way every root step on this laptop is typed:

```
sudo -v && rhx git.grove.house.set house-1 --mode apply
```

the skill writes ONE box file — the election, `house-1` declared under a root-owned dir — and
then drives the host's own bundle through the one door, `grove.provision --what <n>.house`
(F11; the `machine.openhours.optin.set` → `5.18.openhours` precedent). the BUNDLE converges the
box: two unix users, a home for each, mode 0700; a slice cap per seat; a key file for the camper seat, and for the
ground seat no file at all — it authorizes his yubikey-held key, since the supervisor runs as his
own uid and can read any file he can (F12); a
loopback-only sshd unit that lets those two seats in and no one else. the skill then writes the
supervisor's two registry rows, `house-1` and `house-1.ground`, and ends on a live proof — an
ssh round trip into each seat — and prints the next command.

so the box state lives in the bundle tree, and the next laptop gets it from the same apply. the
skill holds no `/etc` write of its own.

he runs it a second time out of habit. it prints a column of `•` and changes no byte.

earlier, he had forgotten the `sudo -v &&`. the skill did not hang on a password prompt nor
half-create a user; it declined in one line and printed the exact command to retype.

## .timeline (sketch — flags are proposals, not committed)

```ts
given('[case1] a laptop with the supervisor live, and no house grove', () => {
  when('[t0] human runs `sudo -v && rhx git.grove.house.set house-1 --mode apply`', () => {
    then('the skill writes one election file, then drives `grove.provision --what <n>.house --mode apply`; it writes no other box file itself (F11)');
    then('two users exist: house-1-camper and house-1-ground, each home mode 0700');
    then('house-1-ground holds NOPASSWD sudo; house-1-camper holds none, and no docker group');
    then('a loopback-only sshd unit listens on 127.0.0.1:<port>, AllowUsers the two seats only, PasswordAuthentication no');
    then('ssh.service stays masked — the 2.3.ssh verify still passes');
    then('the camper key sits in the supervisor\'s ~/.ssh; the ground seat authorizes the human\'s yubikey-held key, and no ground key file is minted (F12)');
    then('registry rows house-1 + house-1.ground exist, type=house, at=<seat-user>@127.0.0.1:<port>');
    then('the run ends on a live ssh round trip into each seat, and names the next command');
    then('each seat\'s user slice carries a MemoryHigh + MemoryMax cap (case=9, F10)');
    then('the registry rows are the LAST write, after the round trip: a send to a half-minted grove fails "no grove named house-1", never lands in a home still under construction');
  });
  when('[t1] the same command runs again', () => {
    then('every line reads `•` — no user, key, unit, or row is rewritten');
    then('exit 0');
  });
  when('[t2] the human typed it WITHOUT `sudo -v &&`', () => {
    then('it declines before any write: no user, no unit, no row');
    then('the fix-text is the full `sudo -v && rhx git.grove.house.set house-1 --mode apply` line');
    then('exit 2');
  });
  when('[t3] the laptop held openssh-client only (every local@* box today), and the mint must add the server', () => {
    then('ssh.service AND ssh.socket are masked BEFORE openssh-server installs, so its postinst enables naught');
    then('after the mint, `ss -tln` shows 127.0.0.1:<port> and no :22, no 0.0.0.0, no [::]');
    then('`grove.provision --what 2.3.ssh` verify still passes: the one listener is the declared house unit, on loopback');
    then('if a mask fails, the bundle stops ✋ before the package lands — never installs and then tries to undo');
  });
});
```
