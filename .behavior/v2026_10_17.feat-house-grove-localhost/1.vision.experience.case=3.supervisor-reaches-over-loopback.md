# case=3 — the supervisor reaches the house grove over loopback, and only its own seat

covers inventory rows 15, 16, 17, 18, 32. feel: 😊 happy, with three 🗡️ sharp edges. care:
🔴 critipath — every crew verb rides this reach.

## .narrative

the supervisor dispatches a crew. it types the verbs it types for grove-1, with a different
name and no other change:

```
rhx git.grove.send house-1 --reply --what 'whoami; echo $GROVE_ENV_SERVER'
```

the reply comes back in milliseconds: `house-1-camper`, `house@unix`. no wake, no tunnel, no
ssm — the registry row says `type=house`, so `wake` reports *"a house grove lives on this box;
no wake owed"* and returns 0.

then a crew, curious, tries `ssh house-1.ground`. ground accepts one key only — the human's, on his
yubikey — and the signature needs a finger on it. the supervisor shares the human's uid and his agent
socket, and it still has no finger. the reach times out in seconds and says *"a human touch is
owed"*. the camper seat is the agent's; the ground seat is the human's — held by a touch, since
on this box a file mode cannot split two processes of one uid (F12).

a week later, after an upgrade, the house sshd unit is stopped. the next send fails in one
second, not at a timeout, and the failure names the unit and the command to restart it — the
`sudo -v &&` line a human runs, because the supervisor cannot.

## .timeline (sketch)

```ts
given('[case3] house-1 minted and converged', () => {
  when('[t0] supervisor runs `git.grove.send house-1 --reply --what whoami`', () => {
    then('it answers house-1-camper, exit 0, with the command\'s own exit code');
    then('`git.grove.wake house-1` reports no wake owed, exit 0 — never an ec2 call');
    then('`git.grove.del --orphaned` does not list house-1: type=house is not checked against ec2');
  });
  when('[t1] supervisor opens `duct://house-1/main/mechanic`', () => {
    then('the duct rides ssh to house-1 — never the "localhost = this machine" shortcut');
  });
  when('[t2] supervisor tries `ssh house-1.ground`', () => {
    then('the only key ground accepts is the human\'s yubikey-held one; no file key exists to offer (F12)');
    then('with no touch the signature never comes; the reach is bounded and fails loud — "a human touch is owed" — never hangs the duct');
  });
  when('[t3] the house sshd unit is stopped', () => {
    then('the send fails fast, not at a timeout');
    then('the fix-text names the unit, and the `sudo -v && rhx git.grove.house.set house-1 --mode apply` repair');
  });
  when('[t4] a host on the LAN dials <box-ip>:2201', () => {
    then('connection refused — the unit listens on 127.0.0.1 only');
  });
  when('[t5] supervisor runs `git.grove.ready.verify house-1`', () => {
    then('each rung climbs both seats and prints them on separate lines');
    then('rungs that ask ec2 or ssm decline for type=house, beside the reason');
  });
});
```
