# case 5 — the clamp proves the receipt, and bites without it

## narrative

the clamp is `prove.play-run-all-reads-three-verdicts`. it copies the real `play.run.sh` into five
temp git repos, each with stub plays, and drives `--all` in each:

- **mixed** (pass, decline, fail) — it counts the `what=all/*.stdout.log` files before and after:
  exactly one new. it reads that file's literal last line: `      └─ 1 passed · 1 declined · 1 failed`.
  exit 1
- **declined** (pass, decline) — one new log, last line `… · 1 declined · 0 failed`, exit 2
- **green** (pass) — one new log, last line `1 passed · 0 declined · 0 failed`, exit 0. it then
  drives `--all --play` and an unknown flag in the same repo, and recounts: still one log
- **empty** (no tracked play) — exit 2, `✋ ConstraintError`, zero logs
- **stamps-taken** — it pre-creates a `<stamp>.stdout.log` for every second across a window wider
  than the try bound, then runs: exit 1, `💥 MalfunctionError`, no new log, every pre-made file
  still empty

then the mechanic proves it bites: revert `play.run.sh` alone to main and run the clamp. main writes
`<stamp>.pid<N>/summary.log`, no flat log, so mixed, declined, and green each fail on the count;
empty exits 0 where 2 is owed; stamps-taken exits as the suite says where `💥` is owed. the clamp
exits 1. restore the change: green. both runs are cited in 5.3. a clamp that stayed green on the
revert would be rewritten, not shipped.

## bdd
