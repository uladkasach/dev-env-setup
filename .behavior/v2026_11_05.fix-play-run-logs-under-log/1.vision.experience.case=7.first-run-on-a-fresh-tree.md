# case 7 — the first run on a fresh tree

## narrative

the mechanic clones the repo and runs `--all` for the first time. no `.log/` dir exists. the runner
makes `.log/role=mechanic/skill=play.run/what=all/`, claims the first stamp, and writes the run's
tree there. before the run, the director had no file to read and showed `unread`; after it, the
director reads one log, last line the tally. no halt, no prompt, no hand step.
