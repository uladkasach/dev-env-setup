## the run matrix — 270 cells

### reachable count

a cell is reachable ⟺ (L = `absent` → H = `none` ∧ S = `free`) ∧ (L = `present-unwritable` →
S = `free` ∧ R = `after-run`) ∧ (O = `empty` → S = `free` ∧ R = `after-run`).

the R criterion: a `mid-run` read exists only where the runner reaches the log dir. an upstream
halt (empty index, unwritable dir) leaves no in-flight window.

| O | L = absent | L = present-writable | L = present-unwritable | per O |
|---|---|---|---|---|
| each of the 4 non-empty | H1 × S1 × R2 = 2 | H3 × S3 × R2 = 18 | H3 × S1 × R1 = 3 | 23 |
| `empty` | H1 × S1 × R1 = 1 | H3 × S1 × R1 = 3 | H3 × S1 × R1 = 3 | 7 |

reachable = 4 × 23 + 7 = **99**. impossible (the union I1 ∪ I2 ∪ I3 ∪ I4) = 270 − 99 = **171**.
