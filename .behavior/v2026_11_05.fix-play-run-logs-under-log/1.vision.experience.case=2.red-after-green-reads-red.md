# case 2 — a red run after a green one reads red

## narrative

this morning's run was green. the mechanic edits a bundle and runs `--all` again; one play fails.
the terminal prints `💥 prove.c-fails — failed (exit 1)`, the summary, and a `💥 MalfunctionError`
on stderr that names the log dir. the director reads the tree: the newest stdout log is the red one,
its last line `└─ 1 passed · 1 declined · 1 failed`. the cell turns red — not this morning's stale
green. this is the walk that fails if the file name does not sort by time, or if the red run
wrote no new file.
