# case 1 — a green suite reads green

## narrative

the mechanic finishes a change and runs `rhx play.run --all`. the terminal prints the verdict tree,
its `logs:` line names the new stdout log, and it closes with `🌲 every play passed`. yesterday's
log already sits in the dir. later the director's ship report reads the tree: the newest
`*.stdout.log` by mtime (the reader's rule, `director.bar.operations.sh:176-181`) is today's, its last line is `└─ 3 passed · 0 declined · 0 failed`, and the
green cell lights.
