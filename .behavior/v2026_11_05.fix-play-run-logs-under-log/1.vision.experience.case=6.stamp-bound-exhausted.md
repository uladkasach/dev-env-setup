# case 6 — every stamp is taken, and the run says so

## narrative

the mechanic starts `--all` while another process has claimed every stamp the run would try — a
runaway loop, or a hand-made file. the runner tries its bounded number of seconds, meets an extant
log at each, and stops before any play runs: `💥 MalfunctionError: could not claim a free stdout
log under .log/role=mechanic/skill=play.run/what=all after N tries`, with the fix (read the dir; a
loop may write there). exit 1. no prior log is overwritten, so the director still reads the last
honest verdict. it fails fast, loud, and names where to look.
