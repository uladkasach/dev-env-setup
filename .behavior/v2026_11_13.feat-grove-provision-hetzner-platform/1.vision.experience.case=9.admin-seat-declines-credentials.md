# case=9 — the ground seat meets a credentialed bundle

feel: happy · care: critipath

## .narrative

a cloud grove splits its users: ground holds sudo and converges box-wide facts; camper does the work and carries the camp identity. the boot applies the whole tree on ground first (step 2), so ground walks every bundle — the credentialed ones too. ground is the admin seat: it holds no aws identity, by design, and the gate expects none on it. so each credentialed phase first asks which seat it stands on, and on ground it declines with a 🌙 that names the camper as the seat that owns the work. no aws read, no rack read, no `aws.params` write; ground's plan ends with zero claims. the same phases then run on camper (step 3) as the camp identity.
