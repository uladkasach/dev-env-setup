# case=10 — a tailnet grove's host key, first contact and rebuilt

feel: sharp · care: critipath

## .narrative

a hetzner grove has no console and no boot record, so no channel attests its host keys the first time a laptop meets it. the wake proves reach anyway: ssh's host-key refusal is an answer from the box, so the boot reaches its trust step. trust.gen scans the keys over the tailnet. its plan is a survey: it lists each fingerprint and says it would need `--trust tofu`, exit 0. its apply refuses in tailnet words (no console, no hibernate) and names the tofu apply. the human confirms the tailnet names the box and accepts by their own word. the boot's halt hands the trust to trust.gen and resumes with `--trust verified`, never `keep`: once the key is laid, trust.gen answers "already trusted", so the resume re-proves the trust and does not loop.

later infra rebuilds the box. the key on record CHANGED. trust.gen refuses, names no local port, and names an attested replace: a key still on record pins an ssh to the box, and the box reports its own new keys. the replace drops the stale entry from the file it appends to, so the old key never stays beside the new one. if no key on record still matches, no channel attests the rebuild, and the human compares the scan to infra's printed fingerprints first.

## .timeline

```
given a hetzner grove on the tailnet, and an empty known_hosts on this laptop
when [t0] rhx git.grove.trust.gen --grove <g> --mode plan
  then each fingerprint is listed, and the plan ends
       `plan: would need --trust tofu — a tailnet box has no boot record to attest`  (exit 0)
when [t1] rhx git.grove.trust.gen --grove <g> --mode apply
  then ✋ `a tailnet box has no boot record, so these keys are unattested` (exit 2)
  then it names `tailscale status` and the `--trust tofu` apply; no ec2 console text
when [t2] rhx git.grove.trust.gen --grove <g> --mode apply --trust tofu
  then the offered keys are trusted
given the boot halted at its trust step
when [t3] the human reads the halt
  then its fix lines run trust.gen (plan, then tofu); its resume is `--from 1 --trust verified`, never `keep`
given infra rebuilt the box: the ed25519 key changed, the ecdsa key did not
when [t4] rhx git.grove.trust.gen --grove <g> --mode apply
  then ✋ host key CHANGED; it names infra's fingerprints and `--on-changed replace`; no local port
when [t5] rhx git.grove.trust.gen --grove <g> --mode apply --on-changed replace
  then the box attests its new key over ssh pinned to the ecdsa key; the stale entry is
       dropped from known_hosts and the new key filed
```

clamp: `prove.tailnet-grove-is-reached-and-trusted` 2o-2x, `prove.boot-steps-name-each-verdict` arm 3.
