# case=3 — hetzner, no platform declaration

feel: sharp · care: critipath

## .narrative

a hetzner box whose bootstrap predates the platform write. camper runs an apply over ssh. no probe answers: dmi names the board maker, the declaration is absent, the desktop rung declines an ssh seat, IMDS is silent. the derivation refuses by name — it never guesses `local@unix`. the error lists both escapes: the one-run override, and the durable fix — the grove's boot findserts the file from the registry's `--platform`, over the ground seat. a box the boot has laid never meets this case.

## .timeline

```
given a hetzner box, /etc/grove/platform absent
  and the seat is ssh
when [t0] rhx grove.provision --mode apply
  then it exits 2 with `✋ ConstraintError: cannot tell which machine this is`
  then the text names `GROVE_ENV_SERVER=cloud@hetzner.hetzbot`
  then the text names /etc/grove/platform and the boot (`git.grove.set --platform`, then boot) as its writer
  then no bundle ran
when [t1] GROVE_ENV_SERVER=cloud@hetzner.hetzbot rhx grove.provision --mode apply
  then the run reads as case=1 [t0]
```
