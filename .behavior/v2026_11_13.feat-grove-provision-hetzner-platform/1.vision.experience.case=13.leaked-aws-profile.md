# case=13 — a fresh zsh exports AWS_PROFILE on a camp grove

feel: sharp · care: critipath

## .narrative

a camp grove's identity is live: `[profile ambient]` mirrors infra's endpoint, it exports credentials, a bare region resolves, the credentials file is present. every declared check is green. one line in a file a zsh reads, `~/.zshenv` or a hand-written `~/.zprofile`, exports `AWS_PROFILE='ambient'`.

keyrack reads `os.envvar` before any vault. so that one value outranks every rack entry on the box, for every org and every env. a suite that asks the rack for its prep account gets `ambient` back, runs as the camp role, and fails on each aws call with an access refusal that names no cause. the prep hop itself is declared and proven, so no other check points at it.

`5.6.aws verify` is the one reader that catches it. it unsets the variable, starts a fresh non-interactive zsh, and asks what that shell exports. a value there came from a file, never from the caller's env. the verdict is a ✋ that names the shadow and the bundle that owns `~/.zshenv`.

## .timeline

```
given a camp grove (cloud@hetzner.hetzbot or cloud@aws.ec2), the camper
  and [profile ambient] declared, mirrored, and live
  and ~/.zshenv (or ~/.zprofile) exports AWS_PROFILE='ambient'
when [t0] rhx grove.provision --what 5.6.aws --mode plan
  then every declared-and-live check reads ✔ first
  then ✋ `a fresh non-interactive zsh exports AWS_PROFILE='ambient'` (rc 1)
  then it says keyrack checks 'os.envvar' FIRST, so the value outranks every rack entry
  then it says the value came from a FILE a zsh reads, since the probe unset it
  then it names `rhx grove.provision --what 2.5.zsh --mode apply`
when [t1] rhx grove.provision --what 2.5.zsh --mode apply
  then ~/.zshenv is the repo's, and it exports no AWS_PROFILE
when [t2] rhx grove.provision --what 5.6.aws --mode plan
  then `a fresh NON-INTERACTIVE zsh exports NO AWS_PROFILE ✔`
```

clamp: `prove.hetzner-default-profile-survives`, case `5.6.aws verify · hetzner, a fresh zsh exports AWS_PROFILE` ([t0]); the converged case pins the ✔ line ([t2]).
