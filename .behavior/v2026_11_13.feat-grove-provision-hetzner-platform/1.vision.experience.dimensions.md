## .dimensions

each axis names one fact a different party controls; that ownership split is why they vary independently.

| # | dimension | values | owned by — why orthogonal |
|---|---|---|---|
| D1 | platform | `aws.ec2` · `hetzner.hetzbot` (declared) · hetzner, undeclared · hetzner, declared as another platform · `unix` · a registry `--platform` that no box declares | the box's builder; fixed at build, before any identity or run. the last value is the provisioner's registry entry, refused before it can reach a box |
| D2 | identity state — **cloud platforms only** | live (ec2 role attached / hetzner serve wired) · not wired (ec2 no role / hetzner `[default]` absent) | infra's admin apply; a cloud box of either platform can sit in either state. scoped to cloud on purpose: "does this box have a platform identity at all" is D1's tier, not a second axis |
| D3 | run | plan · first apply · repeat apply | the provisioner, per invocation |
| D4 | `~/.aws/config` on entry | clean · prior fenced hops · stale ec2-shape fenced hop · hand-laid unfenced hop | the box's history (prior applies, hand edits) |
| D5 | writer order on hetzner | bundles first · identity skill re-runs after · both at once | two schedulers, neither aware of the other |
| D6 | seat | camper (no sudo, the camp identity) · ground (root-capable, the admin seat: no aws identity, as ruled) | the user split, set by infra's bootstrap |
| D7 | target role's trust | admits this grove's session · admits only the ec2 path · admits the camp role, refuses what a roles-anywhere session carries (source identity, session tags) | infra's admin, per target role |
| D8 | `--for` against the probe | absent or agrees · contradicts (a lens) | the provisioner's flag, independent of what the box is |
| D9 | caller | a human at a duct · unattended (a clone, a timer) | who launched the run; decides whether a human can type an override |

D3 is answered once, aloud, rather than per row: **a plan makes no write**, so every cell's plan column is the same experience as its apply, with each upsert reported as owed instead of done. case=1 [t0] demos the plan once; no other case repeats it.
