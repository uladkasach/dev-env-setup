# 1.vision — a busy grove never hibernates itself; an idle one still sleeps

## .the outcome world

### before

a cloud grove's idle check (`/usr/local/bin/idle-hibernate.sh`, every 300s, limit `PT3H`) takes
the newest of boot time, brain trace mtimes, and `/dev/pts` mtimes. its brain trace list holds one
row: `/home/*/.claude/projects`. every fleet clone writes its trace inside its worktree, at
`.agent/.actors/<actor>/brain/.claude/projects/`. the check sees none of them.

so a grove with a dozen crews at work reads as idle three hours after the last human keystroke,
calls `StopInstances --hibernate` on itself, and every crew dies. 0901 did this twice on
2026-10-22. today it is held awake by hand: a stopped timer, plus a stopgap drop-in that runs a
`pgrep` pre-check.

### after

the idle check counts every crew:

| signal | reads | holds the box while |
|---|---|---|
| boot floor | `/proc/uptime` | the box resumed under 3h ago |
| human brain | `/home/*/.claude/projects/**/*.jsonl` | a trace was written under 3h ago |
| **crew brain, worktree** | `/home/*/git/*/_worktrees/*/.agent/.actors/*/brain/.claude/projects/**/*.jsonl` | same |
| **crew brain, main clone** | `/home/*/git/*/*/.agent/.actors/*/brain/.claude/projects/**/*.jsonl` | same |
| keystroke | `/dev/pts/*` | a human typed under 3h ago |
| **crew duct** | every tmux server on the box, each window's `#{window_activity}` (pane output) | a duct printed under 3h ago |

the newest wins. a busy grove never sleeps; an idle one — no fresh trace, no active duct, no
keystroke — sleeps at 3h exactly as before.

the check lands in this repo as a bundle, `1.system/1.15.hibernate`. the ground seat converges it
on every cloud grove with one apply — no rebuild, no root volume wipe. the same trace list and the
same max-reader land in `ahbode/infrastructure` so a fresh grove is born right.

### the aha

a grove's journal reads, every tick:

```
idle-hibernate: hold — idle=412s limit=10800s, newest=trace .../dev-env-setup.beav.fix-grove-idle-counts-every-crew/.agent/.actors/actor.via.repo=ambient/brain/.claude/projects/<dir>/<id>.jsonl
```

the question *"why is this box awake?"* — or *"why did it sleep?"* — answers itself from one line,
with the path of the crew that held it. before, the check was silent on hold, so the defect was
invisible until it fired.

## .the contract, testdriven

### the bundle

```
src/grove.provision/1.system/1.15.hibernate/
  _.sh                      # declines unless $GROVE_ENV_SERVER == *@aws.ec2
  idle-hibernate.sh         # the check — byte-owned, copied to /usr/local/bin
  configure.upsert.sh       # root via bundle.root.owns: write check + units by temp-then-rename (a tick
                            #   never reads a torn file), drop the stopgap, arm timer
  configure.verify.sh       # cmp check + units, no foreign drop-in, timer enabled + active
```

### the check's output

| verdict | stream | line |
|---|---|---|
| hold | stdout | `idle-hibernate: hold — idle=<n>s limit=<n>s, newest=<trace\|duct\|pts\|boot> <source>; seen traces=<n> pts=<n> ducts=<n>` |
| sleep | stdout | `idle-hibernate: sleep — idle=<n>s limit=<n>s, newest=<kind> <source>; seen traces=<n> pts=<n> ducts=<n> — hibernate now` |
| a source unreadable | stderr | `idle-hibernate: 💥 MalfunctionError: <kind> unreadable — <why>` + a `└─ fix:` line; the run exits 1 |

the hold line and the unreadable line go beyond the wish. each earns its place by the defect it
would have exposed: today's check was silent on hold, so a grove that never counted its crews read
healthy until it killed them; and the duct signal rests on a recalled tmux rule (A3), so its one
failure mode must be visible.

### the clamp

`.play/permanent/prove.idle-check-counts-every-crew.play.sh` drives the checkout's
`idle-hibernate.sh` against a hermetic fixture root, with the stop act in `plan` (no aws call):

| case | before the fix | after |
|---|---|---|
| worktree trace fresh | ✋ red — verdict `hibernate` | ✔ `hold` |
| all stale | ✔ `hibernate` | ✔ `hibernate` |
| real tmux server in the fixture, session active | ✋ red — `hibernate` | ✔ `hold` |

## .mental model

> *"the grove only sleeps when nobody's home — and every clone counts as somebody."*

a motion-sensor light that only watched the front hall, while the whole crew worked in the back
rooms. the fix puts a sensor in every room.

| a human says | we say |
|---|---|
| "the box went to sleep on us" | the grove hibernated itself |
| "it thought no one was there" | the idle check saw no stir |
| "the clones" / "the crew" | crews, each with a brain trace and a duct |

## .evaluation

**pros**
- fixes the measured defect at its cause: the trace list, not a `pgrep` beside it
- extant groves heal with one ground apply, no rebuild
- the hold line names the crew that held the box — the next diagnosis is one journal read
- the broken pipe dies by the same edit, which the larger trace set would otherwise worsen

**cons**
- two writers deliver one check: infra at first boot, this bundle on every apply. they must
  converge to the same logic (F2)
- the globs encode the clone layout `/home/*/git/<org>/[_worktrees/]<repo>` (F4)
- the duct signal needs root to reach another user's tmux server (assumption A3)

**edgecases**
- a crew in a long silent tool call with no pane output for 3h → the box sleeps. accepted: no
  evidence of work for 3h is the definition of idle
- an unreadable source contributes no evidence, as infra's check already does for an unmatched
  glob — and now says so on stderr (case 7)
- a laptop or a camper apply declines; the verify still reads and reports (case 8)

## .groundwork

### external research

📌 both facts below are recalled from the manuals, not fetched this round. each is load-bear, so
each gets a measurement before the code depends on it:

- systemd.exec `IgnoreSIGPIPE=` — recalled default true for services. it explains why `sort`
  reports EPIPE where an interactive shell sees a silent exit. measured at stage 5: the clamp runs
  the pipe with `trap '' PIPE` and must reproduce `Broken pipe` against today's check
- tmux `server-access` (3.3+) — recalled: the server owner and root are always permitted to attach.
  measured at stage 5 on a grove, from the ground seat
- `aws ec2 stop-instances --hibernate` — unchanged; the act stays as infra wrote it

## .what is awkward

- **two writers, two repos.** infra writes the check once at first boot; this bundle rewrites it on
  every apply. infra compacts comments away, so the bytes differ and a fresh grove's first plan
  reports drift until the ground apply. the logic must match; the bytes cannot.
- **the duct signal is activity, the wish says presence.** *"no duct"* reads as presence. activity
  matches the doctrine infra already paid for (a forgotten pane billed ~13h) and still holds every
  duct that does work. a one-line rework if the wisher wants presence (F1).
- **the bundle re-arms a timer a human stopped.** a deliberate hold by hand is undone by the next
  ground apply (F3).
