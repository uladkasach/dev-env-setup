# 1.vision.experience.dimensions

the axes, each a closed set, each with why it is orthogonal to the rest. the walked product lives
in `1.vision.experience.case=_.md`.

## .the tick axes — what one 5-minute tick meets

the tick's actor is a single value: **system** — the systemd timer, with no human. no felt actor is
invented for it. the people who meet its outcome are named per experience in the inventory: the
crew clone (held or slept) and the commander (who reads the journal and pays the bill).

| axis | values | orthogonal because |
|---|---|---|
| **B. newest evidence kind** | boot floor only · human trace · worktree trace · main-clone trace · codex session trace · duct output · keystroke | which source is newest is set by who worked last; it fixes no age, no readability, no volume |
| **C. newest evidence age** | fresh (< limit) · stale (≥ limit) | any source can be any age; the boot floor too (a box up 1h vs 10h) |
| **D. signal read** | all readable · some unreadable (one or more sources, up to all) · a source names hostile bytes (a forged verdict line, a terminal escape) | readability, and the bytes a source hands back, are facts about permissions, tools, and whoever wrote the name — independent of who worked or when |
| **E. trace volume** | the mtime list fits one pipe write · it spans many writes | the boundary is the reader's write buffer (4 KiB on a pipe, ≈370 mtimes): past it, a reader that exits early fails the next write. volume is history and says naught about the newest one |
| **S. SIGPIPE disposition** | ignored (the systemd unit, recalled default — A1) · default (a hand run from a shell) | set by who launched the check, independent of volume; E alone does not decide the symptom — E × S does |
| **H. concurrent interaction over the read→act window** | none · a crew writes a trace · a ground apply writes the check or units · a second tick starts · a second ground apply runs · the tick hibernates the box under an in-flight apply | every other process that touches the tick's inputs, its unit, or is touched by its act; independent of what the box holds |
| **J. the check's own record** | written clean · cannot be written (no dir, a failed rename) · holds a line the check did not write | the record is the check's OUTPUT and the next tick's wake floor; whether `/run` takes the write is independent of what the tick read or how it acted |
| **I. act outcome** | not reached (hold) · withheld (a sleep verdict, but the reads ran past their window, so the act would not fit the unit's bound) · StopInstances accepted · StopInstances refused or fails · not callable (no aws on PATH, or imds gives no id) | set by aws, imds, and the time the reads took — independent of what the tick read |

⚠️ the earlier axis `E. box state` (just resumed) is folded into B: a fresh boot floor IS the newest
evidence of a resumed box, so the two were one axis.

## .the apply axes — what one `grove.provision --what 1.15.hibernate` meets

| axis | values | orthogonal because |
|---|---|---|
| **A. seat** | ground (root, `*@aws.ec2`) · camper (no root, `*@aws.ec2`) · laptop (`local@*`) | the seat is chosen by who runs it, not by what the box holds |
| **M. mode** | plan (the default) · apply | the mode is chosen at the keyboard, independent of seat and box |
| **G1. check on the box** | infra's old check · converged to the checkout · converged bytes, held at the wrong mode or owner · a symlink where the check belongs · infra-born with the fixed logic (compacted bytes) · absent (userdata died early) | the check's state is history of writers, independent of the seat now at the keyboard |
| **G2. drop-ins beside the units** | the stopgap (0901) · a foreign drop-in systemd reads · a file in a `.d` dir systemd does not read · none (every other grove) | a hand fix on one box, independent of the check it wraps |
| **G3. units, as systemd holds them** | timer active · timer stopped by hand · timer disabled · timer masked · a unit not loaded · a reload owed (old definition live) | runtime facts, independent of the files on disk |
| **K. apply step outcome** | every step answers · a systemd verb fails (`daemon-reload`, `unmask`, `enable --now`, `restart`, `reset-failed`) · a systemd verb hangs past its bound · the drop-in list is unread · a file verb fails (stage, install, chown, rm, rmdir, the stopgap rm) · the checkout lacks a declared file | set by systemd, the filesystem, and the checkout the seat holds — independent of what the box held before the apply |
| **R. unit health, as the verify reads it** | the last tick ran clean · the last tick failed · the last tick was killed by its bound · an `ExecCondition=` drop-in skipped the tick · a non-clean result with no record, or a record with no verdict line · a needed tool absent from the unit's PATH (`aws`, `setpriv`) · systemd does not answer a read | runtime facts of the unit, its record, and its PATH — independent of whether the files on disk match the checkout |

⚠️ `G` was one axis that fused `old check` with `stopgap`, so the common extant grove — old check,
timer active, no stopgap — had no cell. split into G1 × G2 × G3.

⚠️ K names a CLASS of fault per value, never one verb: each verb in a class fails the same way —
a qualified `💥` that names the verb and what still holds on the box, exit 1, no later step, and
the next apply retries. the class is the experience; the verb is which line of it a human reads.

⚠️ a laptop holds no check at all, so on `local@*` the G axes do not apply. the laptop row is one
forbidden cell for the whole G product (the platform gate rejects it), recorded as such in the
inventory.
