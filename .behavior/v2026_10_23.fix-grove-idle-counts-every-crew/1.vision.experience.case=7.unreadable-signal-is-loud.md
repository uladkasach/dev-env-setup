# case 7 — a signal is unreadable, and says so

critipath · sharp — the fail-safe direction, and what makes it visible.

> ⚠️ **5.1 diverged from this case, and the call is the council's (F6).** the shipped check
> HOLDS on an unreadable source and exits 1, so the drift reader names the pin on the next plan;
> it never sleeps a box whose crew it could not see. the block below shows the shipped lines; the
> narrative and timeline beneath it keep the sleep the vision first asked for, for the council to rule.

## .narrative

a crew on the commander's grove died overnight, and the commander opens the idle-hibernate journal to
learn why. beside the hibernate line sits an alert that names the cause:

```
idle-hibernate: 💥 MalfunctionError: duct unreadable — tmux at /tmp/tmux-1001/default did not answer: <tmux's error>
   └─ fix: <the read the check names for that source>
idle-hibernate: hold — idle=10844s limit=10800s, newest=trace <path>; seen traces=<n> pts=<n> ducts=0; but 1 source(s) unreadable (💥 above), and a box the check cannot read is held, never slept
```

so the commander knows in one read that the box did not judge the crew idle — it could not see the
crew's duct. the fix line says where to look. no CloudTrail hunt, no guess.

**the behavior under it.** a tmux upgrade tightened its access rule, so root's read of a camper's
socket was refused (or a find walk hit a dir it could not read). the check cannot tell *"no crew"*
from *"could not ask"* by the answer alone, so an unreadable source contributes no evidence — as
infra's check already does for an unmatched glob. that keeps one failure direction: the box may
sleep, and the bill never runs away. what is new is that the tick says so, every time.

## .timeline

```
[t0] given the commander's grove, whose crew's tmux socket root cannot attach to, and every trace stale
[t1] when the idle check ticks
[t2] then the journal names the socket and the refusal, with a fix line
[t3] then the duct contributes no evidence, and the verdict follows the readable signals
[t4] when the commander reads the journal
[t5] then the cause is on the page beside the hibernate line
```

## .why not fail toward awake

an unreadable source that held the box would let any broken socket bill a grove forever, silently —
the 42h-awake class infra already paid for. a loud line plus a sleep is the cheaper wrong.
