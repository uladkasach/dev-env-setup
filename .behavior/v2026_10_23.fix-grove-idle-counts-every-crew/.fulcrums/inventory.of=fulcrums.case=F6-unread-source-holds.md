# F6 — a source the check cannot read holds the box, and the hold surfaces

## .the fork
- **hold** — any unreadable source turns a would-be `hibernate now` into a `hold` that names the
  count of unread sources
- **sleep, loud** — the `💥 MalfunctionError:` lines print, and the box sleeps if no read source is
  fresh (vision case 7)

## .taken — hold, exit 1
the two errors cost unequally. a wrong sleep kills every crew on the box — the defect the wish exists
to end. a wrong hold bills one more tick, under a `💥 MalfunctionError:` line in the journal.

a hold forced by an unread source exits 1, so the unit's `Result` reads `exit-code`, and the bundle's
drift reader names it: `the last idle check ended 'exit-code' — read why: journalctl …`. a camper
plan on any grove then shows the pin, so a source unreadable for good (a tmux server older than its
upgraded client, say) is named on the next provision rather than left to bill in silence. the timer
fires again whatever the last result was.

## .the pin's fix never ends a crew (i008)
the canonical pin is a server older than its upgraded tmux: `protocol version mismatch`, for as
long as its crew lives. the fix-text once said to restart it — the act that kills the crew this
hold protects. `duct_fix` now prints a non-destructive read for that text: dial the server with
the binary it runs (its pid's exe link in procfs), and the hold lifts when its crew ends. arm
`mismatch.why` pins the text.

to dial that exe from the check itself would count such a server rather than hold on it. it would
run as the socket's owner, never root — `dial_duct` drops to the owner with `setpriv` before any
dial — so root's reach is not the cost. the cost is that the check would run a binary the seat
named, as that seat, and trust its rows; that is the same trust the owner drop already grants a
seat's own tmux. the pin is rare (the tmux the grove ships keeps one protocol across its
upgrades), so the dial is left for the wisher's call beside this hold, not built.
