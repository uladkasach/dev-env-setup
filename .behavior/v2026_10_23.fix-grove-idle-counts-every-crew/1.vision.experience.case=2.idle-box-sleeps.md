# case 2 — the commander's idle box still sleeps

critipath · happy — the fix must not cost the bill.

## .narrative

the commander's crews wrapped up at 14:00. nobody tells the grove; nobody needs to. the next day the
commander checks the camp bill and sees the grove stopped compute at about 17:00 — three hours after
the last crew went quiet, the same as before the fix. the journal's last line before the stop says
why:

```
idle-hibernate: sleep — idle=10844s limit=10800s, newest=trace <path>; seen traces=<n> pts=<n> ducts=0 — hibernate now
```

the fix that keeps busy groves awake did not keep this one awake: every trace, every duct's last
output, and every keystroke was older than three hours, so it slept.

## .timeline

```
[t0] given every trace, every duct's last output, and every pts older than the limit; uptime > limit
[t1] when the idle check ticks

[t3] then it calls StopInstances --hibernate on its own instance
```
