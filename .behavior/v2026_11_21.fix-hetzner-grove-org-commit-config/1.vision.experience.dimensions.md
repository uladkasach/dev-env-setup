# 1.vision.experience.dimensions

## .actors

| actor | where they stand | what they want |
|---|---|---|
| provisioner | `grove.provision` on the grove (a clone or the human) | the seat's meter allows each org the token can push to |
| crew | a crew tree on the grove, as `camper` | commit + push at the done gate |
| human | his own terminal | a block he set stays set; his local meter stays his choice |
| clone | any tool call | it may run the apply; it must not grant past the token |

## .dimensions

| # | axis | values | orthogonal because |
|---|---|---|---|
| d1 | seat | crew (`camper`, `cloud@*`) · admin (`ground`) · local grove (`local@unix`) · ci runner (`local@cicd`) | a property of WHERE the run stands; fixed before any read |
| d2 | the token's push orgs | some · none · unread | set where the token is minted; free of the seat's meter |
| d3 | per token org, meter state | allowed · blocked · unset · `@all` allowed · `@all` blocked · corrupt | a human's past act on one file; free of the token and the moment |
| d7 | moment | provision plan · provision apply · crew done gate | which act reads the meter |
| d8 | concurrency | alone · an apply while a reader reads · two applies at once | time order between two acts |
| d9 | a crew tree's own org vs the token's orgs | in the set · not in the set · names no org | the gate keys on the CREW tree's `org:`; which crews land on a seat is the sprout's act |
| d12 | the meter read | parses · jq absent · jq present but does not parse · meter present and its read fails | a property of the seat's tools and disk |
| d13 | the meter write | lands · fails | a property of the seat's disk |
| d14 | the apply's jq install, where jq is absent | lands · fails | a property of the seat's package source |

## .the walked product

**d1 first.** only `crew` carries rows. a local grove (e11), a ci runner (e12), and the admin seat
(e10) each decline whatever the other axes hold — one cell each.

**d2 on `crew`.** `some` is the core below. `none` = e39 (apply 🌙, verify ✋). `unread` = e38
(✋ names `5.4.gh`). each of the two stops before d3 is read for a write.

**`crew × some` × d3 × d7, the core.** every cell carries its inventory id:

| d3 \ d7 | plan | apply | crew gate |
|---|---|---|---|
| unset | e1/e15 ✋ names the apply | e1 allows it | e15 ✋ upstream refusal |
| allowed | e14 ✔ | e14 no write | passes |
| blocked | e5 🌙 honored | e5 left as is | e18 ✋ upstream — his own block |
| `@all` allowed | e6 ✔ via `@all` | e6 no write | passes |
| `@all` blocked | e7 🌙 honored | e7 no write | e18 ✋ upstream — his own block |
| corrupt | e8 ✋ | e8 ✋, never written over | e19 💥 upstream malfunction |

**d12, under every read:** parses = the core · jq absent or broken = e34 · read fails = e35. each
stops before any verdict on d3.

**d14, under `jq absent` on an apply:** lands = e42, then the core · fails = e42 ✋, before any read.

**d13, under `apply` × unset:** lands = e1 · fails = e40.

**d8:** an apply while a reader reads = e20 · two applies at once = e22.

**d9:** the core walks `in the set`. `not in the set` = e23: one cell for every d3 value, since the
apply never allows such an org. `names no org` = e28: the tree fails on its own keyrack before
the gate, so the verify names it with a 🌙.

**forbidden:** an apply that grants past the token or lifts a block (e17) · a clone that types a
grant into a duct (e21).
