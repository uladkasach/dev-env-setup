# case=5 — a crew of an org the token cannot push to

sharp × critipath · crosses sprout · token read · provision · crew gate

the gate keys on the org a crew tree's `.agent/keyrack.yml` declares, never its github owner. on
hetzner every crew tree declares an org the token reaches. this case is the fail-safe for the first
crew whose manifest names another org.

## .narrative

a crew of otherorg was sprouted onto a grove whose token cannot push to otherorg. no meter grant
can help it: the push would fail on the token even past the gate. so the verify reads each crew
tree's org and names the trees outside the token's reach, with the two moves that help:

```
✋ ConstraintError: crews of org 'otherorg' live on camper@<grove>, and the token cannot push to them
   ├─ otherorg: svc-w
   └─ fix: widen the token's scope (rhx git.grove.auth.github.set <grove>), or sprout those crews on a grove whose token reaches them
```

the tree's org is read only to REPORT. the apply never allows an org the token cannot push to.

a tree whose keyrack names no org fails on that keyrack before the gate, so the verify names it
with a 🌙 and no ✋.

## .bdd sketch

```

[t4] then   otherorg stays unset in the meter
```
