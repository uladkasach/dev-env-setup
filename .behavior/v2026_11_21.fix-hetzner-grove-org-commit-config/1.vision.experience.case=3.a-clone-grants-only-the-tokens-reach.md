# case=3 — a clone grants only what the token reaches

sharp × critipath · the safety edge of an auto-grant

## .narrative

a clone on a crew seat meets case=2's refusal and runs the fix the plan named:
`rhx grove.provision --what 5.26.commitorgs --mode apply`. that is sanctioned. the apply can allow
only the orgs the grove's token can push to, which a human set where the token was minted. it
never allows another org, never lifts a block, and never writes over a damaged meter.

the doors a clone must not take stay shut:

- `rhx git.commit.uses --org <org> allow` typed into a duct: forbidden by
  `rule.forbid.self-grant-human-gates`. the writer's tty guard cannot tell a duct from a human,
  and this work opens no road to it
- the apply on a local grove: it declines, because a local meter is the human's own choice and no
  fact on the box answers it
- the apply on the admin seat: it declines; crews commit from the crew seat

```
🌙 declined — on a local@unix grove the org commit meter is the human's own choice
   ├─ why: no fact on the box answers which orgs the human's clones may commit for
   └─ who: the human, at their own terminal; this output holds no command a clone could run
```
