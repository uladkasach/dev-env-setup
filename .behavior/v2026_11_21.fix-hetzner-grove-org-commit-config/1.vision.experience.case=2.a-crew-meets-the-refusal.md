# case=2 — a crew meets the refusal at its done gate

sharp × critipath · crosses crew gate · meter · provision

## .narrative

a grove whose provision has not yet run this bundle's apply. a crew of ehmpathy finishes its route
and runs `git.commit.set`. the upstream gate refuses:

```
✋ no org config for ehmpathy (org permissions not configured)
```

the crew must not write the meter by hand. it fails fast (before any commit) and loud. the fix is
the grove's own provision: a plan on that seat already names it, and an apply clears it.

```
✋ ConstraintError: the commit gate finds no grant for orgs '<org3>', 'ahbode', 'ehmpathy' on camper@<grove>
   ├─ why: a crew of each is refused at its done gate: 'no org config for <org>'
   └─ fix: rhx grove.provision --what 5.26.commitorgs --mode apply   # it allows each token org
```

## .bdd sketch

```
[t0] given  a crew seat; org meter absent; a crew tree with quota + sponsor
[t1] when   the crew runs git.commit.set --mode apply
[t2] then   ✋ no org config for ehmpathy; exit 2; no commit made        (upstream)
[t3] when   rhx grove.provision --what 5.26.commitorgs --mode plan on that seat
[t4] then   ✋ names each unset token org and the apply
[t5] when   the apply runs
[t6] then   case=1 `[t5]` onward holds
```

⚠️ the upstream fix-text lives in rhachet-roles-ehmpathy; its text is that repo's to make.
