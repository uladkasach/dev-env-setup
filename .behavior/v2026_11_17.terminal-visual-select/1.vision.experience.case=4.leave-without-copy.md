# case=4 — leave the selector, with or without a copy

holder any · the LEAVE that ends every session, whatever its intent · happy · critipath (a view with no way out traps the human) · walks D3 (view key) × D7 (selection state)

## .narrative

the human pressed super+v to read back a few lines, and has read them. they want out, now, with no surprise.

three keys leave from anywhere in the view: super+v (the key that opened it), ctrl+x (the escape key everywhere else on this desktop), and q. none of them copies on the way out, so an exit never overwrites the clipboard. ctrl+c with no selection also leaves, in either holder, so the copy key never traps them in a dead view.

## .the key table, both holders

| key | selection `none` | selection `active` |
|---|---|---|
| right-alt+j / k | move the cursor a line | grow or shrink the selection a line |
| enter | begin a selection | end it, stay in the view |
| ctrl+c | leave | copy, keep the selection |
| super+v | leave | leave; the selection is dropped, not copied |
| ctrl+x | leave | leave; not copied |
| q | leave | leave; not copied |
