# case=2 — select and copy lines in a plain kitty window

holder `kitty.main` · intent `copy` · happy · critipath

## .narrative

a plain kitty window, no tmux: a quick shell to check a log. kitty owns the history here, and kitty has no keyboard selector of its own.

the human presses super+v anyway. an overlay covers the window, the same text as before, the last line at the bottom where their eye already was. it is an nvim view of that history, read-only. the gesture is unchanged: right-alt+k to walk up, enter to start a line selection, right-alt+j/k to grow or shrink it, ctrl+c to copy (the toast confirms), enter to end it. super+v or ctrl+x closes the overlay, and the shell is exactly as it was.

they did not need to know which holder they were in. the keys were the same.

## .timeline

```
given a kitty window with no tmux, a shell on the main screen
  when [t0] super+v
    then an overlay opens over the window, with the scrollback as read-only text
    then the cursor is on the last line of text
  when [t1] right-alt+k ×3, then enter
    then a line selection begins 3 lines up
  when [t2] right-alt+k ×2
    then the selection spans 3 lines
  when [t3] ctrl+c
    then the 3 lines are on the clipboard, and a toast says so
    then the selection stays
  when [t4] enter
    then the selection ends
  when [t5] super+v
    then the overlay closes; the shell is untouched
```
