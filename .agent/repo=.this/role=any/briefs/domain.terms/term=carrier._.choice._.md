# domain.term: carrier

term.chosen   = carrier
term.kind     = noun
term.synonyms.forbidden:
- transport (as the noun for ONE of a pair — see `.reason`)
- backend
- method
- mechanism
- strategy

## .what

one of the interchangeable tools that move a tree between a laptop and a grove. today
`rsync` and `tar` — `git.grove.push` and `git.grove.pull` each pick one, and the pair
must hold ONE policy.

a carrier is a **holder** (`term=holder`), so the pair is m.9 by construction: two
carriers, one policy, and the cheaper one is free to drift.

## .the invariant a carrier pair owes

> **whatever a caller asks, both carriers must produce the same OUTCOME** — the same
> layout, the same exclusions, the same refusals. a caller does not choose a carrier for
> its behaviour; it chooses one for what its box HAS.
