## .where a new brief goes

name it for its SUBJECT, then file it under the cluster that owns that subject
(`rule.require.group-by-noun-not-verb`). a brief that fits two clusters names two
subjects — split it.

## 🛑 .a move is a READER-SCOPE event

a brief is cited two ways, and only one of them rots:

- by NAME — `rule.forbid.repair-plays` — survives any move
- by PATH — a path-shaped citation — does not

⇒ **cite by NAME.** a path is owed only where a reader must open the file: `boot.yml`,
`.claude/settings.json`, a skill that reads it.

⚠️ measured twice. `.agent/playbooks/` moved to `.play/` and four readers went silently
blind, every verdict green (`evidence/gotcha.a-check-that-cries-wolf-gets-silenced`, q11).

⇒ `prove.brief-pointers-reach` is the clamp: it reads every path-shaped pointer in the
tracked corpus and demands each reach a file.

```sh
rhx play.run --play prove.brief-pointers-reach
```

## .the prefixes

| prefix | what it is |
|---|---|
| `rule.require.` / `rule.forbid.` | a blocker |
| `rule.prefer.` / `rule.avoid.` | a nitpick |
| `gotcha.` | a trap that BIT, with the measurement that found it |
| `hazard.` | a property that HOLDS and will bite — present tense, no measurement owed |
| `define.` | a term or a model, stated once |
| `howto.` / `howdoes.` | a procedure a human runs; an account of how a subject works |
| `plan.` / `handoff.` / `inventory.` | live state, owned by a human |

⚠️ `gotcha.` and `hazard.` are the two halves of ONE axis — **has it fired?** — and they are
not synonyms. a hazard can earn a gotcha the day its property fires; a gotcha can never become
a hazard, because a measurement does not un-happen. **a hazard with a measurement inside it is
a gotcha misfiled.** `domain.terms/term=hazard._.choice._.md` carries the full split.
