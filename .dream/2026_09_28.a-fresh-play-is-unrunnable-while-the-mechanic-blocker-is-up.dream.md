## .the cue that fired

a clamp was written to hold the `keyrack.gitroot` capability —

⇒ so for the whole span the blocker was up, the clamp existed and could not be executed.

## .the gap, precisely

`play.run` takes a slug against **the git INDEX**, by design and for a stated reason: *"a
pulled tree can place a file here"*, so an unindexed file is untrusted content. that reason
is sound, and it composes badly with one other live fact:

| the gate | what it holds | its reason |
|---|---|---|
| `play.run` | a play must be in the INDEX | a pulled tree can drop a file into `.play/` |
| the mechanic blocker | `git.stage.add` is refused | a human paused every mechanic write to git |

each is correct alone. together they close the loop: **the only sanctioned way to index a
play is the one operation the blocker refuses**, so a play authored under a blocker is
unrunnable by construction — the clamps this repo's own rules demand among them.

🔴 and the two rules that demand them are live:

- `rule.require.seam-claims-have-an-owner` — *"a seam check never exercised against a
  deliberate break = nitpick"*
- `gotcha.a-check-that-cries-wolf-gets-silenced` — *"a check proven in one direction only is
  half proven"* · *"a check earns its keep by RUNNING, not by sitting in a directory"*

⇒ so the state this produces is the exact one that decays a check set: a `.play/permanent/`
dir that accumulates unrun files, each of which reads as protection and guards no claim.

⚠️ **and the failure is quiet in the worst way.** an unrun clamp does not redden. it reads
green-by-absence, and a later reader counts it as coverage — which is m.13's shape (*"a check
NOBODY RUNS decays into a false ✋ on its own"*) with the run never even attempted.

## .why it is not done in this round

the SAFE/CLEAN test fails on CLEAN, decisively:

- the fix is in `rhachet`'s `play.run`, or in the blocker's own scope — neither is this
  repo's file
- and it is no small local edit either: it asks *"what may a play read that the index has not
  vouched for?"*, which is a security boundary, not an ergonomics one

⇒ and the deferral is a JUDGMENT about ripple, so it earns a fulcrum beside this dream
(`rule.always.fix-forward-under-scouts-honor`, its dirt clause).

## .the shape of the fix

three candidates, cheapest first. each is a real option and the choice is a human's:

1. **a `--from tree` axis on `play.run`** — the same word `grove.provision` already uses for
   *"read the worktree, not what is committed"*. it keeps the index as the DEFAULT (so a
   pulled tree still cannot smuggle a play into an ordinary run) and names the exception out
   loud at the call site, which is what `rule.require.exemptions-name-their-trigger` asks
2. **narrow the blocker** so an author can index a `.play/**` file while the rest of git
   stays paused. ⚠️ weaker: the blocker's scope is the human's, and to carve it for the
   robot's convenience inverts who is protected
3. ⛔ **a permission for a bare `bash <play>`** — reject this. it routes around `play.run`
   entirely, so no play would draw the runner's own guards, and it is the same defect shape
   as a hand-run `rhx review` (`rule.forbid.hand-run-reviews`: an instrument outside the
   system, for a real need the system should serve)

⇒ candidate 1 is the one to price first.

## ⚠️ .the interim, and it is not a workaround

until then: **author the clamp anyway, and say in its header that it is unrun.** an unrun
clamp with its state declared is honest; an unrun clamp presumed green is the decay above.

⇒ and DELETE that line on the first run that passes, never before. `prove.rack-reads-a-foreign-org`
carried it, then earned its removal — its header now records the first-run date and what
that run caught, which is the durable half. the unrun declaration was the temporary half.
