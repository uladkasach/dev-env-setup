# 🌙 dream: this public repo names no org past ahbode and ehmpathy

- kind: fix (dox)
- owner: dev-env-setup
- caught 2026-11-22

## .the cue that fired

the human: only ahbode and ehmpathy may be named publicly. a third org surfaced in a clamp fixture
of `5.26.commitorgs`; that branch was scrubbed before any push. main still names it.

## .the gap, precisely

on main, a third org (and a fourth) appear in about twenty tracked files, in two classes:

- **code that depends on the name**: the github-name map in `src/grove.org.sh` (`GROVE_ORG_GHORGS`),
  the per-org arms in `5.10.repos`, `5.12.rack`, `5.13.reach`, `5.16.keys`, a node pin note in
  `5.1.node`, the per-org aws aliases in `2.7.aliases/bash_aliases.sh`, and `prove.org-scoped-rows`
- **prose**: briefs under `creds/` and `grove/play/`, comments in `git.grove.rack.operations.sh`,
  `prove.pnpm-pins-need-no-wire`, and several dreams

git history keeps every past copy; a redaction stops growth, it does not unpublish.

## .the shape of the fix

1. move each per-org table whose key is an org past the two public ones out of tracked source:
   read it at run time from a private holder (the org's own keyrack manifest, or a file infra
   provisions onto the box), so the code carries the mechanism and no org name
2. redact the prose: placeholder orgs (`<org3>`) per `rule.forbid.dox-in-public-repo`
3. widen `rule.forbid.dox-in-public-repo` so its table names "an org past ahbode and ehmpathy" as
   dox, and add the names to the dox check the pr body and diff already pass through

## .why it is not done in this round

the code half is a design change across five bundles and their clamps, outside the behavior this
pr ships (it ships only the org commit gate). the human decides where the per-org tables live.
