dream = fix the declapract `cycles` gate upstream — its `// "^$"` fallback is **dead syntax**
and has never fired, in any yq, in any version

## .the gate, as declapract stamps it

```sh
dpdm --exclude "$(yq -r '.exclude | join("|") // "^$"' .dpdmrc.yaml)" …
```

the `// "^$"` tail reads as *"and if `.exclude` is absent, fall back to `^$`"*. it is not one.

## 🛑 .measured 2026-09-11 — `join` raises BEFORE `//` is ever reached

fed a yaml doc with no `.exclude` key, on this box:

| engine | what it printed |
|---|---|
| go-yq 4.53.6 | `Error: cannot join with !!null, can only join arrays of scalars` |
| jq 1.7 | `jq: error (at <stdin>:0): Cannot iterate over null (null)` |

**both engines, same cause.** `//` is jq's *alternative* operator: it catches a `null` or `false`
**produced by** its left side. it does not catch an **error raised inside** it. `join` raises on
`null` rather than returning one, so the right side is unreachable.

reordered, it works in either engine:

```sh
yq -r '.exclude // [] | join("|")'   # → empty, no error
```

⇒ the alternative must precede the `join`, never follow it.

## .the cost, and why it is quiet

the gate wraps the filter in a `$(…)`, so an error collapses to an **empty string** and the
command becomes `dpdm --exclude "" …`. dpdm then scans `node_modules` and reports hundreds of
cycles that do not exist — a false ✋ on every run, which is the shape that gets a check silenced
(`gotcha.a-check-that-cries-wolf-gets-silenced`).

⚠️ it fires only where `.dpdmrc.yaml` **omits** `.exclude`. every repo that declares one takes
the working arm and never sees it, which is why it has survived.

## .the survey — the stamp is not uniform

read across `node_modules` on 2026-09-11, ~12 packages carry a `cycles` entry in `package.json`
and they do not agree:

| shape | example |
|---|---|
| the filter, with the dead tail | most |
| the filter, **no** tail | `domain-objects` |
| a literal `--exclude '^$'`, no yq at all | `type-fns`, `iso-time`, `helpful-errors` |

⇒ so the fix upstream is a template edit, and the drift means several stamped repos will need
a re-stamp to pick it up.

## .the fix

```sh
dpdm --exclude "$(yq -r '.exclude // [] | join("|")' .dpdmrc.yaml)" …
```

`// []` before the `join` yields an empty string where `.exclude` is absent — which is what
`^$` was reaching for, and is in fact what dpdm wants (an empty `--exclude` and a `^$` exclude
mean the same thing to it).

## ⚠️ .this repo asserts only the arm that is REAL

`5.17.yq`'s verify runs the gate's filter byte-identical and asserts the `.exclude`-**present**
arm only. it deliberately does **not** assert the fallback: that branch is an upstream defect,
never a fact about which yq is installed, and a check that reddens over somebody else's dead
branch is a false ✋.
