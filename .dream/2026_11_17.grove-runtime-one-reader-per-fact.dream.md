## .the shape of the fix

1. `grove_aws_identity_road_refusal road= endpoint=` in `src/grove.aws.sh`; callers add only their fix line. one read that returns road and endpoint together
2. derive `own` from the platform (`grove_env_server_platform`), never the endpoint
3. a seat declaration at registration: `bundle.upgrade <slug> --seat camp`, the driver declines once
4. `grove_env_platform_declarable` in `src/grove.env.sh`, read by every site above
5. move the ssh operations to `src/grove.ssh.sh`; `_git_grove_del` calls `grove_ssh_owned_config` and `grove_ssh_host_block_drop`
6. `grove_file_swap` — symlink-follow, `flock`, mode, cleanup — with the `[default]` guard as a thin layer on top

7. `grove_registry_reach <grove>` → `tunnel|tailnet`, fail closed; stop the `type:"ec2"` stamp on a hetzner entry
8. the grammar clamp moves into `grove_ssh_alias_set`; the findsert quotes with `printf %q`
9. boot operations take their inputs as arguments; `halt` returns a code; boot runs `git.grove.wake <grove>.ground`
10. `play.clamp.verify --patch <file>` reverts one named hunk with `git apply -R`
11. the boot defers the keys claim by name on its own side, never through an env var a bundle reads

12. the policy gets one box-wide owner (a `1.x` bundle), re-fenced from a `DPkg::Post-Invoke` hook off the package's dist
13. `play.clamp.verify` runs the play in a throwaway `git worktree` with the reverted files swapped in
14. `grove_aws_has_camp_identity` in `src/grove.aws.sh`, on the road reader, fail closed on an unknown platform; every `aws.params` write and every ambient-identity decline asks it

each lands with a play arm that goes red when one copy drifts.

## .why it is not done in this round

each is a cross-file contract move: (3) touches every credentialed bundle and the driver,
(5) moves a file two skills and the aliases source, (6) changes four writers' swap at once.
none is a defect a box hits today — every copy agrees and is clamped where it stands — so
each is clean to do as its own change, and dirty to smuggle into this route's diff.
