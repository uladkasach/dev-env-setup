# 🌙 dream: a git.repo.get test run leaves the real ~/.gitconfig byte-equal

- kind: reseed
- owner: ehmpathy/rhachet-roles-ehmpathy, the `git.repo.get` skill
- caught 2026-11-22

## .the cue that fired

a credential read on the laptop opened `~/.gitconfig` and found it 806904 bytes,
11406 lines. all but a handful are `[safe] directory = /tmp/git-repo-get-test-<rand>/home/git/<org>/<repo>`
— five per fixture run (`testorg/short`, `medium-name`, `very-long-repo-name`, `a`,
`otherorg/another-repo`), so ~2,280 runs of that fixture each appended to the human's
real git config.

## .the gap, precisely

- the fixture ran `git config --global --add safe.directory <repoPath>` against the real
  HOME. upstream main dropped that line (route `v2026_08_12.fix-require-gitrepoget`; its
  test now notes no global `safe.directory` is set)
- but no step removed the residue it left, and no clamp proves a test run leaves the real
  `~/.gitconfig` unchanged — so any older branch or pinned checkout that still carries the
  old fixture keeps the growth alive, and a future fixture could reintroduce it unseen
- git reads every line of `~/.gitconfig` on every invocation; 11k dead lines tax every git
  call on the box, and each points at a temp dir long gone

## .the shape of the fix

1. the fixture runs under a hermetic HOME (`HOME=<tmp>`, `GIT_CONFIG_GLOBAL=<tmp>/gitconfig`),
   so `--global` can never reach the human's file
2. a clamp: hash the real `~/.gitconfig` before and after the suite; a diff fails it
3. a one-time prune for boxes that ran the old fixture — remove only `safe.directory`
   values under `/tmp/git-repo-get-test-*`, never any other line:
   `git config --global --get-all safe.directory` → filter → `git config --global --unset-all safe.directory '<regex>'`
4. find which branch or checkout still runs the old fixture on this laptop, and retire it

## .why it is not done in this round

the source and its tests live in ehmpathy/rhachet-roles-ehmpathy, not this repo, and the
file is the human's own dotfile — a prune there is the human's call, not a crew's edit
