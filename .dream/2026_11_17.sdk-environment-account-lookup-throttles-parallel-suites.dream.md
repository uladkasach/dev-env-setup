# 🌙 dream: sdk-environment's account lookup throttles a parallel suite

- kind: reseed (owner: ehmpathy/sdk-environment)
- caught 2026-11-17

## .the cue that fired

the hetzner grove gate ran `ahbode/svc-chat`'s integration suite twice. both runs failed only on
`TooManyRequestsException: Too Many Requests` from AWS's Account API, thrown in
`getEnvAccessFromAwsAccountName`. 8 failures, then 11, on different files.

## .the gap, precisely

`getDatabaseConnection` calls `getEnvironment()` once per test file. each call asks the Account API
for the account name. jest's parallel workers burst those calls past the API's rate limit.

## .the shape of the fix

in sdk-environment: memoize the account-name lookup per process (or on disk with a short ttl), and
retry a throttle with backoff before it surfaces.

## .why it is not done in this round

the fix belongs to another repo, and the human ruled sdk-environment out of this route's scope.
