## .carry the MEASUREMENTS, never just the file

each is why the skill beats a re-write, and each was paid for once:

1. **the shebang picks the parser, never the extension** — a `.sh` file with `#!/usr/bin/env zsh`
   parsed by bash is a false ✔ **and** a false ✋, in one reader (measured 2026-08-14)
2. **`find`, never `**`** — a glob shrinks silently without `globstar`: `src/grove.provision/**/*.sh`
   expands one level, so ~150 bundle files go unparsed behind a clean verdict
3. **a COUNT in the verdict, and `exit 2` at zero** — a run that matched no file must not read
   like a pass (`rule.forbid.failhide`)
4. **`.cache` / trash pruned** — `rmsafe` MOVES rather than deletes, so a naive walk parses every
   file the repo ever deleted (measured 2026-08-13: the count could not fall)
5. **an unknown flag HALTS** — `--paths`, one character off `--path`, was swallowed by a
   `*) shift ;;` arm; the run reported a verdict about a subject the caller never named. it
   printed 311 files, identical to the unnarrowed run, and that identity was the only tell
6. **a SKIP is printed beside the verdict**, never folded into it
7. **the root is SEARCHED, never hardcoded** — a hardcoded `$HOME/git/more/dev-env-setup` names
   MAIN's checkout on every box. run from a worktree on 2026-07-30 it reported
   `all 29 files parse` for a tree that had DELETED every one of them
