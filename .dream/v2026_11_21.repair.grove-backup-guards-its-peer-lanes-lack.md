## .the gap, precisely

1. **the digest repacks the fleet on any library edit.** `grove_backup_pack_rules_digest`
   hashes the whole library, so a comment repacks every unit on every grove, and
   `grove_backup_units_stalest_first` sorts by mark `at` alone, so a dirty tree waits behind
   that repack
2. **a mark vouches for a key, never its bytes.** a same-day overwrite of a quiet unit's key,
   or a planted object with a copied `Metadata.sha256`, holds the ✓ on bytes no pass wrote
3. **a worktree unit's repo identity is never proven.** the writer takes the clone's basename;
   the reader checks only that `$target/.git` exists, so a foreign clone at that path takes
   the graft
4. **the run lock's fd 9 (and the restore's fd 8) rides into every child.** an orphan child
   holds the lock; every later pass exits 0 with no status until the 2h STALE line

## .the shape of the fix

1. split the library in place behind the same function names: `unit` (the digest hashes this
   file whole), `bucket`, `box`, `pack`, `status` (the verify sources this alone). store the
   digest in the mark apart from the git fingerprint; order a pass changed-first, then
   rule-stale. measure the first pass on hetzner first (`sudo journalctl -u grove-backup`)
2. add `ETag` as a fourth column of the json list seam; the mark records it; the quiet check
   and step 3 compare key and etag. every `read -r key lastmod class` reader names the fourth
3. writer: the clone's realpath must equal `~/git/$org/$repo`, else the tree rides as an
   orphan. reader: `restore_live_is_this_repo` asks whether the unit's root commit is one of
   the live clone's, after the pack indexes; a mismatch refuses, named, with `--into`
4. re-exec the agent under `flock -n -o "$state/run.lock"`, so the lock lives in `flock`
   alone; the same for the restore's seat lock. measure first: `sudo lsof` on the lock
   between passes
