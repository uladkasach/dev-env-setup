# 🌙 dream: the permission hook reads only `allow`, so every `ask` entry is dead

- kind   = fix
- owner  = `rhachet-roles-ehmpathy` (the mechanic role's `claude.hooks/pretooluse.check-permissions`)
- caught = 2026-09-28

## .the cue that fired

a new skill was authored with the `Write` tool, which lands a file at `100644`. rhachet execs a
skill directly, so it answered:

```
/bin/bash: line 1: …/skills/git.grove.auth.ssh.set.sh: Permission denied
```

the repair is one exec bit. `chmod +x <path>` was blocked. it was retried — the hook's own text
says *"If you've considered the alternatives and still need this specific command, retry it"* —
and the retry printed the identical block. no prompt ever reached the human.

## .the gap, precisely

`.claude/settings.json` declares THREE permission buckets, and the hook consults ONE:

| bucket | what the human meant | what the hook does |
|---|---|---|
| `allow` | run it, no prompt | ✔ permits |
| `deny` | never run it | ✔ refuses |
| `ask` | **prompt me, then run it** | ✋ refuses, as though denied |

the hook fires at `PreToolUse`, ahead of the harness's own permission evaluation. so its refusal
is terminal: the ask-flow it was meant to defer to never runs.

⇒ **the five entries in `ask` are unreachable today**, and the config gives no sign of it:

```json
"ask": [
  "Bash(bash:*)",
  "Bash(chmod:*)",
  "Bash(npm install:*)",
  "Bash(pnpm add:*)",
  "Bash(pnpm install:*)"
]
```

### 🛑 .why this is worse than an absent entry

an absent entry reads as absent — a human who wants `chmod` adds it and moves on. an entry in
`ask` reads as **granted, save for one prompt**. so the config states a capability the machine does
not have, and the only party who could notice is whoever reads both the config and the hook's
source in one pass.

that is `gotcha.a-check-that-cries-wolf-gets-silenced`, m.4: the verdict is true — `chmod` is
indeed absent from `allow` — and its SUBJECT is wrong. the question the hook asks is *"is this
pre-approved?"* and the question it answers is *"is this permitted at all?"*

### ⚠️ .the cost is not the one bit

two costs, and the second is the larger:

1. **every new skill this repo authors is born unrunnable.** `Write` cannot set an exec bit and
   every skill beside it is `100755`, so the wall is structural rather than incidental — it fires
   on the next authored skill, and the one after.
2. **`pnpm install` and `pnpm add` are in that same dead list.** a `pnpm patch` workflow — the
   sanctioned in-repo lever for a defect in a dependency, and the one this repo needs for
   `ehmpathy/rhachet#559` — cannot complete its `pnpm patch-commit` without them.

## .the shape of the fix

the hook must read all three buckets and act per bucket:

| the command matches | the hook |
|---|---|
| `deny` | refuses, as today |
| `allow` | permits, as today |
| `ask` | **returns without a verdict**, so the harness prompts the human |
| none of the three | refuses with the alternatives list, as today |

a hook that cannot express *"defer to the harness"* is the narrower defect beneath this one. where
its protocol offers no such exit, the honest second-best is to treat `ask` as `allow` **and say so
in the refusal text**, so a reader learns the bucket was seen rather than skipped.

⚠️ what the fix must NOT be: a wider `allow`. to move `chmod` into `allow` retires the prompt the
human deliberately asked for, which trades a correct defect for a security regression
(`rule.require.security-paramount`). the bucket is right; its reader is wrong.

## .why it is not done in this round

- **SAFE?** no. the hook is the mechanic role's, and it gates **every** `Bash` call in every repo
  that boots that role. a change there is a change to a security boundary, and the blast radius is
  every session everywhere rather than this one file.
- **CLEAN?** no. it lives in `rhachet-roles-ehmpathy`, outside this checkout, so it cannot ride
  this diff at all. a tree adopts only what is scoped to itself
  (`rule.always.scope-onetime-lessons-to-the-behavior`).

⇒ so it is a **reseed**, and the local remedy is one line typed by a human:

```sh
chmod +x .agent/repo=.this/role=any/skills/git.grove.auth.ssh.set.sh
```
