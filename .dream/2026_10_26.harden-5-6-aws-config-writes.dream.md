## .drafted in that route, then split out unmerged

the commander split these out of the tailscale pr: credential-path rewrites no grove had run do
not ride a pr about another subject. the drafts sit, whole, in `.temp/split.credential-path-repairs/`
on the laptop that drove the route — a start, never a proof:

- the config write is atomic, and an unclosed fence halts with the file as found
- a failed IMDS role read is a `💥 MalfunctionError`, never "no role"; an absent curl too
- `declare_org` refuses an undeclared org by name and writes atomically

  `prove.auth-github-set-arg-contract`

⚠️ one defect the drafts carry, found in review: the atomic write's `mktemp` + `mv -f` replaces a
symlinked `~/.aws/config` with a plain file and resets its mode. write through the link's target,
or keep the mode and refuse a symlink by name, before the draft lands.

## .the gap left, precisely

1. **a token-curl failure on an ec2 box still reads as "not ec2"** — exit 0, no profile. the
   token read cannot tell a timeout from a laptop without the ec2 probe's answer
2. **`[default]` is appended unconditionally** — a human `[default]` outside the fence is
   shadowed with no message
3. **`5.12.rack` copies three facts it does not own**: keyrack's ssm path, `5.6.aws`'s profile
   name, `5.13.reach`'s env table
4. **`ehmpathy:prod` gets `ambient`** while the upsert's own comment says only camp does
5. the no-role refusal returns 1 where a constraint is 2 (check what `bundle.upgrade` reads)
6. positional args in `declare_org` / `declared`; inline printf blocks want named leaves
7. **`git.grove.auth.github.set.sh` inlines its remote steps** — the IMDS probe, the keyrack
   `list`/`get`/`set` strings, `REMOTE_STEPS` — in the orchestrator
8. **five skills reach into `grove.provision`'s aliases** for the sink `__duct_strip_escapes`, by
   one relative path to `2.7.aliases/ductwork.sh`: `git.grove.auth.github.set`,
   `git.grove.auth.keys.set`, `git.grove.operations`, `git.grove.play.await`, `aws.ec2.get`. the
   first also reaches `~/.bash_aliases` and `__term_as_ssh_host`
9. **main's `5.16.keys` declare helper and `prove.rack-consumers-are-dispositioned` play hide
   failures**: an empty `gitroot` writes `/.agent/keyrack.yml`; `mkdir`, `cd`, and the `tee`
   write fail with no message, and the `tee` is not atomic; `rev-parse` and `realpath` sink
   stderr, so a read failure reads as "not a checkout"; one header is a bare 🌙

## .the shape of the fix

- 1: pass the ec2 probe's verdict in; a token failure on a box the probe CLAIMS is a 💥
- 2: a `[default]` outside the fence → write only `[profile ambient]`, and 🌙 say so
- 3: read each from its owner's function, or a shared leaf both bundles source
- 4: decide whether the camp role may hop to ehmpathy prod; if not, the row goes
- 7: one named leaf per remote question (`grove_auth_imds_answers`, `grove_auth_rack_answers`, …)
- 8: lift the sink and the clamp into a shared leaf under `src/` (beside `grove.web.sh`) that
  `ductwork.sh` and all five skills source — one change, so no skill is left the odd one out
- 9: refuse an empty or relative `gitroot` with a 💥; qualify every refusal; write via a temp
  file and `mv`; let `rev-parse` and `realpath` speak, and treat only "not a repo" as absence
- clamps: the three drafted plays above, run on a woken ec2 grove before the merge

## .why it is not done in that round

the drafts above, and all nine gaps, need a woken ec2 grove to prove, and the tailscale pr is the
wrong carrier for them.

1 and 4 change what an ec2 grove's identity resolves to, and no grove was reachable to prove
it. 3 and 6 are refactors that ripple into `5.13.reach`. 7 and 8 reshape a credential path that
only a woken ec2 grove can prove; 8 also spans four skills this route never touched. 9 sits in
code this branch left identical to main, so its fix is a change of its own. fulcrum: F014.
