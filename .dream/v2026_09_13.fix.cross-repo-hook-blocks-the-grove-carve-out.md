## .the cue that fired

a one-bundle apply against a cloud grove — the form
`rule.forbid.the-driver-by-path` declares as **carve-out 3**, and the one the
human runs routinely — was refused by the hook, twice:

```
rhx git.grove.send grove-ahbode-v20260901 --reply --within 600 \
  --what 'bash $HOME/git/more/dev-env-setup/src/grove.provision._.sh --what 2.8.tmux --mode apply'

🛑 BLOCKED: adhoc cross-tree access — Bash
   path: ~/git/more/dev-env-setup/src/grove.provision._.sh
   repo: uladkasach/dev-env-setup (your repo, but a different worktree)
```

## .the gap, precisely

the hook reads the whole bash command as a set of **local** paths. it is right
about the string and wrong about the box:

| what the hook believes | what is true |
|---|---|
| `$HOME` is this laptop's home | `$HOME` is the grove seat's home — the string is sent, never expanded here |
| the path names a peer worktree | it names a checkout on a machine reached over a duct |
| a direct read is a trap | the grove's checkout was just pushed from this very tree |

⇒ the refusal is a **false ✋**, and the class it blocks is not marginal:
`rule.forbid.the-driver-by-path` names it as the routine way a change reaches a
grove, and forbids a new skill written to wrap it.

⚠️ the second half is what makes this expensive. with the send blocked and a
wrapper forbidden, the one route left is the full
`rhx git.grove.provision boot --mode apply` — every bundle on both seats, where
one was owed. on a box under load that is the difference between a minute and
an hour.

## .the shape of the fix

the discriminator is already on the command line: the path sits inside a
`--what` payload of a **transport** skill, so it is by construction a path on
the far side.

- exempt any path that sits inside `git.grove.send`'s / `duct.send`'s `--what`
  - the hook already parses the command; this is one more branch, not a rewrite
- ⚠️ do NOT exempt the whole command — a `--from` or a local redirect in the
  same line is still a local path and still deserves the check
- the narrower read: exempt a path that begins `$HOME/` **unexpanded**, since a
  literal `$HOME` in a quoted payload is never this box's home

## .why it is not done in this round

- **safe?** no — the hook gates every `Bash` call in every repo that boots this
  role. a wrong branch there opens a real cross-tree read, silently
- **clean?** no — the file lives in `node_modules/.../claude.hooks/`, published
  from `ehmpathy/role=mechanic`. a fix here would be overwritten on the next
  install, and a fix there is another repo's diff

⇒ so it is a reseed, and the fulcrum it carries is: the grove work continued via
the slower `boot` path rather than halt on the hook.
