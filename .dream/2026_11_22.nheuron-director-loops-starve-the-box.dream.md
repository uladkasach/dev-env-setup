- kind  = reseed (owner: `uladkasach/nheuron`; the fix lives there, not here)
- owner = nheuron director + crew skills
- caught 2026-11-22

## .the cue that fired

forks/sec (a calm desktop runs 5–20). `rhx machine.diagnose.loop` and

## .the shape of the fix

1. **every loop dies with its launcher** — a parent-death check each tick
   (`kill -0 $PPID`, or `prctl` PR_SET_PDEATHSIG for node). an orphan under init
   is a defect, not a state
2. **every loop backs off under pressure** — read `/proc/pressure/cpu` `avg10`;
   above a bound (say 40%), stretch the interval ×4 or skip the tick. the box's
   own verdict, read once per tick, costs one file read
3. **heartbeats and crew polls run only in a driven tree** — gate on a live
   claude session bound to that worktree, not on the worktree's existence
4. **batch the github reads** — one graphql query for N issue states, not N
   `gh issue view` calls
5. **every `mktemp -d` owns a `trap 'rm -rf "$dir"' EXIT`** — a temp dir with
   no trap is a leak per tick; at heartbeat cadence that is thousands a day
6. **cap jest workers in the director's test runs** — `--maxWorkers=50%` or a
   fixed small number; a full fan-out on a shared box starves every session

## .why it is not done in this round

the code sits in `uladkasach/nheuron`; this repo (dev-env-setup) only diagnoses.
this session held no nheuron worktree and was asked to calm one machine, not to
change a peer repo's director layer.
