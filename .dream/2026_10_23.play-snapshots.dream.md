# 🌙 dream: every play snaps the ✋ / 🌙 / ✔ it grades, as the route's six plays now do

kind: feature · owner: dev-env-setup · caught 2026-10-23, from `.behavior/v2026_10_23.fix-grove-crew-users-linger` (r10, i006 nitpick 5)

## .the cue that fired

a peer lane named the claim "the repo has no snapshot convention" as wrong, and noted the route's
plays grade each message by one phrase, so a reviewer never sees the whole rendered state a human
meets.

## .the gap, precisely

- `.play/permanent/.snap.operations.sh` holds `play_snap_assert` (masks, `--resnap` via
  `rhx play.run --resnap`, a per-run seen list). six plays call it, with snaps under
  `.play/permanent/__snaps__/<play>/`:
  `prove.coredump-verify-reads-core-pattern`, `prove.linger-reaches-every-seat`,
  `prove.tmux-pin-upsert-fails-safe`, `prove.tmux-verify-refuses-an-unpinned-build`,
  `prove.tmux-verify-names-a-server-behind-the-pin`, `prove.tmux-configure-refuses-an-unpinned-plugin`
- the other 43 plays grade by phrase alone
- no orphan check: a snap whose arm was removed stays on disk, unread
- `brains.auth.test.sh` keeps its own snap helpers; two homes for one practice

## .the shape of the fix

1. port each play whose arms grade a rendered message: source the helper, call
   `play_snap_assert arm=… rendered=… mask=<fixture>` once its phrase holds
2. mask every fixture path; key a snap by any box fact the arm does not own (as
   `prove.tmux-verify-names-a-server-behind-the-pin` keys by the prior tmux build)
3. add `play_snap_orphans` — after the last arm, a snap no arm touched this run reddens
4. fold `brains.auth.test.sh` onto the shared helper

## .why it is not done in this round

safe, not clean: 43 plays this route never opened, each with its own resnap review and its own
masks for the box facts it reads.
