# 🌙 dream: five plays copy `sleep` as a bait, and a uutils host refuses to run the copy

- kind: fix
- owner: uladkasach/dev-env-setup
- caught 2026-11-01

## .the cue that fired

CI on #170 went red on `prove.tmux-pin-upsert-fails-safe` after the runner image moved to
the multi-call uutils coreutils. its log read `coreutils: unknown program 'tmux'`: the
binary reads argv[0], so a copy of `sleep` named `tmux` does not run.

## .the gap, precisely

five plays still copy `sleep` under a new name, so the bait never starts on a uutils host:

| play | line | bait name |
|---|---|---|
| `prove.earlyoom-spares-the-session` | 69, 70 | `systemd`, `node` |
| `prove.coredump-catches-a-crash` | 44 | the coredump bait |
| `prove.abandoned-procs-are-reaped` | 58 | `node` |
| `prove.reaper-spares-an-own-scope-server` | 81 | `tmux` |
| `prove.a-bait-that-never-starts-fails-the-play` | 35 | the real `sleep` it stubs around |

none sits in the CI matrix: each needs systemd, coredump or root. a bait that never starts
fails loud with exit 1 (F16), so on such a host the plays go red rather than false green.
this box and the groves run GNU coreutils, where every one passes.

## .the shape of the fix

- copy `bash` instead, as `prove.tmux-pin-upsert-fails-safe` arm L does:
  `"$BAIT" -c 'trap "kill \$! 2>/dev/null; exit 0" TERM; sleep 600 & wait' &`
- bash runs under any name, and the trap takes its `sleep` child down at cleanup
- check each play's own claim against the new bait:
  - earlyoom and the reaper match on the process NAME, so `comm` must still read the bait name
  - the coredump bait must still crash on SIGSEGV and leave a core with the bait's name
  - the bait clamp stubs `sleep` on PATH, so it must stub the new bait's real program instead
- prove each on a uutils host: red with `sleep` copied, green with bash
